# ml_ops

## 무엇을

NiFi VM의 MLflow 추적·레지스트리, D 학습 실행기, 카나리아·롤백 제어 기반이다.

## 왜

실행의 Delta 버전·특징 버전·코드 커밋과 후보 모델을 연결한다.

## 사용법

[MLflow 운영](../../ops/mlflow/README.md)의 실행 명령과 평가 함수 계약을 따른다. [롤백 런북](../../ops/runbook/rollback.md)에서 보호 설정과 CronJob·수동 실행·별칭 전환 순서를 확인한다.

## 설정값

실제 추적 URI·SSH 키·학습 설정은 보호 파일만 사용한다. 웹 선택 연결은 `PALDO_MLFLOW_MODELS`·`PALDO_MLFLOW_MODEL_CACHE`와 `MLFLOW_TRACKING_URI`를 사용한다. 야간 실행은02:00 서울·Forbid·초기 suspend=true이며 입력·출력 PVC는 각각4GiB·8GiB다.

### 검증

가짜 모델로 메타데이터 누락 거절, 평가 실패 거절, 통과 후 후보 별칭 조회와 Garage 업로드·다운로드를 검증했다. C-10-01은 세 D 관문 등록 경로, 실제 promtool 경보, 격리 레지스트리의 카나리아 30판·대조 138판과 B 버전 고정 포트를 함께 검증했다.

## 한계

야간 CronJob은 중지 상태의 정의를 제공하며 실제 입력 PVC·검수 라벨·이미지 준비 후 수동 Job부터 검증한다. 운영 의심 모델의 매일 밤 재학습·자동 승격은 이 CronJob이 아니라 게임 웹 서버의 systemd 타이머로 돈다([ML 모듈 한계 절](ml.md#한계)). B 운영 조립의 실제 모델 로더 연결과 광고 MySQL 활성 버전 전환은 담당자 인계가 필요하다. 서비스는 인증된 SSH 경로에서만 연결한다.
