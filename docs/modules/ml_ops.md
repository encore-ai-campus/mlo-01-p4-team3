# ml_ops

## 무엇을

NiFi VM의 MLflow 추적·레지스트리와 등록 관문이다.

## 왜

실행의 Delta 버전·특징 버전·코드 커밋과 후보 모델을 연결한다.

## 사용법

[MLflow 운영](../../ops/mlflow/README.md)의 실행 명령과 평가 함수 계약을 따른다.

## 테스트

가짜 모델로 메타데이터 누락 거절, 평가 실패 거절, 통과 후 후보 별칭 조회와 Garage 업로드·다운로드를 검증했다.

## 알려진 제한

D 평가 함수와 웹 모델 선택기 인계가 필요하다. 서비스는 인증된 SSH 경로에서만 연결한다.
