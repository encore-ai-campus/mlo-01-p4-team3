# 시뮬레이션

## 무엇을
- `engine/sim/bots.py`: 무작위·논리 우선·반복 의심·거짓말 공략 플레이어 봇 4종. 입력은 무당의 `PlayerView`와 시드 RNG이며 공개 정보로 합법 명령 후보를 만든다.
- `engine/sim/runner.py`: `GameEngine` 포트로 판을 종료까지 진행하고 거부 명령·명령 상한 초과를 실패로 드러낸다. 판 진실 값은 읽지 않고 엔진에 되넘긴다.
- `engine/sim/report.py`: 정책별 진영 승률·판 길이·무감금률·고백률·의미 있는 선택/판과 분모를 집계한다. 분모가 0인 비율은 비워 둔다.
- 합성 광고 HTTP 트래픽은 `tools/ad_traffic_sim.py`와 `ads/testing/traffic_server.py`가 담당한다. 게임 봇 구현은 변경하지 않는다.

## 왜
게임 봇은 기획서 v1.3 7.3의 같은 시드 반복 실행·비교 지표를 제공한다. D-06-03은 v1.3 9.6절(구판 14.6절)의 정답 CTR을 숨긴 광고 검증이다. 두 시뮬레이션을 분리하고 광고는 실제 HTTP 경매가 선택한 소재에만 클릭 주사위를 굴린다.

## 사용법
게임 봇: `python -m tools.perf.sim_bench --games 200 --seed 7 --preset base6`. 기본 결과는 `out/sim/D-06-01/`이며 정책별 첫 실행 뒤 같은 판을 다시 실행해 trace를 비교한다. 이전 측정은 [D-06-01 증빙](../evidence/D-06-01.md)에 있다.

광고 실행 명령·출력·재현 범위는 [광고 서버 설명서](ads.md#합성-http-트래픽-d-06-03)를 따른다. 0%·5%·20% 수용 측정: `python -m tools.perf.ad_traffic_bench --requests 10000`.

## 설정값
게임 측정 CLI의 기본값은 정책별 200판·seed 7·preset base6이며 runner 명령 상한은 500이다. 판 ID는 preset·정책·실행 시드·판 번호를 포함한다. 봇 버전은 `player-random-v0`, `player-logic-v0`, `player-repeat-v0`, `player-lie-pressure-v0`다. 광고 시드·실행 ID·무효 비율·피로 감소율은 [광고 설정값](ads.md#설정값)에 있다.

## 한계
봇의 우선순위는 규칙이며 학습 확률이 아니다. 합법 후보 목록은 가능한 모든 조합을 망라하지 않는다. 기존 게임 봇의 대량 수치는 이번 태스크에서 다시 측정하지 않는다. D-06-02 MySQL 원장·아웃박스·Kafka 연결은 광고 검증 범위가 아니다. 광고 시험의 가상 시간은 만료·유예 규칙을 재현하며 실제 시간 경과 성능을 증명하지 않는다.
