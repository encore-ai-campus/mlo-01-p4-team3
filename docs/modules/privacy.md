# privacy

## 무엇을

삭제 제외 목록과 Bronze 재유입 필터, 보존 기한 대상 목록 도구를 제공한다.

## 왜

Kafka 보존 사본이 재처리돼도 이미 삭제한 가명이 다시 쌓이지 않게 한다.

## 사용법

[개인정보 삭제·보존 런북](../../ops/runbook/privacy.md)의 저장 위치와 실행 순서를 따른다.

## 테스트

게임·광고·재판정 제외와 별도 참가자 보존 대상 선택을 검사한다.

## 알려진 제한

운영 Bronze는 빈 제외 목록으로 시작했다. 삭제 목록 등록 도구는 저장 위치별 삭제 실행을 대신하지 않는다. DB 및 아티팩트의 물리 삭제·예약 검증이 남아 있다.
