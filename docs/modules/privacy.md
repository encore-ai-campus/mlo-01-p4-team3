# privacy

## 무엇을

삭제 제외 목록과 Bronze 재유입 필터, 게임·광고·Delta·아티팩트 삭제 도구를 제공한다. 웹 VM에서 보존 기한에 참가자 목록을 준비한다.

## 왜

Kafka 보존 사본이 재처리돼도 이미 삭제한 가명이 다시 쌓이지 않게 한다.

## 사용법

[개인정보 삭제·보존 런북](../../ops/runbook/privacy.md)의 저장 위치와 실행 순서를 따른다.

## 테스트

게임·광고·재판정 제외와 보존 대상 선택을 검사한다. 격리 MySQL, Delta 및 Garage에서 대상만 삭제하고 재실행 시 삭제 0건을 확인했다.

## 알려진 제한

운영 Bronze는 빈 제외 목록으로 시작했다. 운영 삭제에서는 승인 대상마다 Gold와 공유 학습·추출 아티팩트의 재생성 범위를 확인해야 한다. 보존 타이머는 보호 스냅숏이 있어야 목록을 만들며 승인된 삭제 절차는 운영자가 실행한다.
