# 에셋 스타일 가이드 (E-05-05 초안)

모든 이미지 에셋(초상·장소/UI 아이콘·지도·광고 소재·발표용 이미지)이 따르는 그림 기준 1장이다. 파일 형식·크기·이름은 [`spec.md`](spec.md)를 따른다. 11/11 일괄 검수(E-11-05, 검수자 B)는 이 문서의 항목으로 판정한다.

- 상태: **초안**. 화풍은 확정(11/4 PM 결정), 화풍 안의 변형(아래 1절 A·B·C)은 **샘플 비교 후 PM 결정 대기**. 검수자 B 확인 대기.
- 생성 도구는 정하지 않았다(P-10). 이 문서는 특정 도구·모델에 기대지 않는다. 도구별 프롬프트 문법은 생성 기록(`SOURCES.md`)에 남긴다.
- 마스코트·로고(P-21), 기색 표정 변형(P-20)은 결정 대기라 다루지 않는다.

## 1. 화풍

**만화풍 평면 채색(셀 채색, 그러데이션 최소)**을 모든 에셋에 같은 화풍으로 쓴다(11/4 PM 결정). 사진풍·3D 렌더·수채 번짐은 쓰지 않는다.

| 변형 후보 | 선 | 명암 | 판단 기준(샘플로 확인) |
|---|---|---|---|
| A. 굵은 외곽선 + 2단 셀 | 먹색, 굵기 일정 | 기본색 + 그림자 1단 | 작은 크기 가독성이 가장 좋고 생성 일관성이 높을 것으로 예상 |
| B. 가는 선 + 한지 질감 배경 | 가늘게 | 인물 평면, 배경에만 옅은 질감 | 분위기는 좋지만 작은 크기에서 질감이 잡티가 될 수 있음 |
| C. 선 없는 면 채색 | 없음 | 면·실루엣으로 형태 | 아이콘은 깔끔하지만 얼굴 구분이 약할 수 있음 |

**결정 대기**: 같은 대상(주모 흉상, 짚신 아이콘)을 세 변형으로 뽑아 ① 128px·32px 축소 가독성 ② 시드만 바꾼 2~3장의 얼굴·화풍 일관성 ③ 글자 섞임을 비교해 PM이 고른다. 고르면 이 절을 그 변형 하나로 줄인다.

- 특정 색을 특정 진영·역할(씐 자, 창귀)과 짝짓지 않는다. 같은 색이 주민 여럿에게 고르게 나오게 한다.

## 3. 선·명암

- 명암은 단계로 끊는다(셀). 부드러운 그러데이션, 강한 역광, 림 라이트는 쓰지 않는다.
- 빛은 모든 에셋에서 왼쪽 위 한 방향이다. 그림자 색은 기본색을 어둡게 한 같은 계열이다.
- 아이콘은 128px 원본을 32px로 줄여도 형태가 읽히도록 도형을 크게, 세부를 적게 그린다.

## 4. 인물 구도

- **초상**: 흉상(가슴 위), 정면 또는 3/4 측면, 얼굴이 화면 위쪽 1/3~1/2에 오고 머리 위에 여백을 조금 둔다. 512×512 정사각형이고, 원형으로 잘라도 얼굴이 잘리지 않게 가운데에 둔다.
- 모든 초상은 같은 눈높이·크기 비율로 그려 나란히 놓았을 때 크기가 튀지 않게 한다.
- **주인공(무당)**: 여 `mudang_f`·남 `mudang_m` 2종, 30대. **약간 미화**한다(정돈된 이목구비, 단정한 무복). 두 버전은 같은 무복 계열·같은 구도로 맞춘다.
- **주민**: 미화 없이 평범하고 자연스럽게, 직업과 나이가 옷·소품으로 드러나게 한다(훈장=갓·서책, 대장장이=앞치마 등). 표정은 평온한 기본 표정 하나로 통일한다.
- 시대는 조선 후기 마을 분위기의 창작 설정이다. 고증보다 인물 구분과 일관성을 우선한다.

## 5. 배경 처리

- **초상·아이콘**: 단색 배경(먹남 `#2E344A` 기본). 배경에 소품·풍경을 그리지 않는다.
- **지도**: 위에서 내려다본 평면 지도. 장소 5곳(우물가, 서낭당, 주막, 마을 어귀, 집)이 서로 구분되게 놓되 **이름 글자는 넣지 않는다**(화면이 쓴다).
- **광고 소재**: 728×90·300×250 안에 대상 사물 하나와 단색·단순 배경. 소재 제목·본문·"광고" 표시는 화면이 쓰므로 그 자리를 비워 둔다(728×90은 오른쪽 2/3, 300×250은 아래 1/3).

## 6. 금지 요소

모든 파일에 아래가 하나라도 있으면 탈락이다(에셋5 체크리스트).

1. **실존 인물**의 얼굴·이름을 닮게 그린 것.
2. **상표·로고**, 실존 상호·브랜드를 떠올리게 하는 표식.
3. **글자**: 한글·한자·영문·숫자, 글자처럼 보이는 낙서·가짜 문자, 서명, 워터마크.
4. **새 게임 정보를 주는 표현**: 씐 자·창귀를 암시하는 표정·눈빛·색·그림자·소품, 특정 인물만 다르게 그린 조명·구도, 범행 장소를 암시하는 지도 표시.
5. **외모를 우스꽝스럽게 깎아내리는 묘사**(과장된 추함, 신체 비하). 외모로 창귀가 짐작되지 않게 한다.
6. 설화 원전의 그림·문장을 그대로 옮긴 것(창작만 쓴다).
7. 선정적·잔혹한 묘사(실종·감금 장면도 상징 소품으로만).
