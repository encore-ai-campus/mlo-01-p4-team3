# 에셋 스타일 가이드 (E-05-05)

모든 이미지 에셋(sprite·초상·표정 변형, 마스코트, 장면 배경, 장소·UI 아이콘, 지도, 광고 소재, 발표용 이미지)이 따르는 그림 기준이다. 파일 형식·크기·이름·기준선(px)은 [`spec.md`](spec.md)를 따른다. 11/11 일괄 검수(E-11-10, 검수자 E)는 이 문서의 8절 체크리스트로 판정한다.

- 상태: 화풍은 PM 결정(11/5, 크로스체크 18). **검수자 B 확인 대기.**
- 제작은 생성형 AI로 한다. 생성 도구는 아직 정하지 않았다(P-10: 반실사 그림체를 고정할 수 있는 도구). 이 문서는 특정 도구에 기대지 않고, 도구별 프롬프트 문법은 생성 기록(`SOURCES.md`)에 남긴다.
- **임시 그림은 최종 화풍이 아니다.** 지금 저장소의 sprite·초상·장면 배경은 회색 실루엣과 이름 표기로 된 크기·기준선·배치 확인용이다(`spec.md` 5절). 크기·기준선·투명 바탕·배치만 실제 그림과 같고, 색·선·채색은 이 문서의 판정 대상이 아니다.
- 자동 검사로 볼 수 없는 항목(화풍, 빛, 선, 닮음, 정보 노출)은 이 문서의 체크리스트로만 사람이 판정한다. 자동 검사 항목은 `spec.md` 6절이다.
- 표정 변형(P-20)과 마스코트(P-21)는 11/5 PM 결정으로 확정했다(크로스체크 19). 표정은 첫 플레이 8명만 평상시·기쁨·당황·슬픔 4개이고 추가 주민은 기본 1장이다(4절). 마스코트는 까치·족제비 2장이고 로고는 만들지 않는다(4절).

## 1. 화풍

**애니풍에 가까운 반실사 일러스트.** sprite·초상·장면 배경·아이콘·지도·광고 소재 전부에 같은 화풍을 쓴다(11/5 PM 결정).

- 인체 비율과 옷 주름은 사실에 가깝게, 얼굴은 애니메이션처럼 또렷한 눈과 단순한 이목구비로 그린다.
- 채색은 부드러운 명암(그러데이션·반투명 가장자리 허용)이다. 사진, 3D 렌더 느낌, 수채·유화 질감은 쓰지 않는다.
- 같은 화풍을 지키는 방법은 2·7절(빛·선·기준 색, 생성 기록)이다. 색 수·반투명은 검사하지 않는다.

## 2. 빛·선

- 빛은 모든 에셋에서 **왼쪽 위 한 방향**이고, 그림자는 오른쪽 아래에 둔다. 인물마다·장면마다 빛 방향을 바꾸지 않는다.
- 외곽선은 먹색 계열의 가는 선이다. 선 굵기는 sprite 원본(512×1280) 기준으로 바깥 윤곽 2~4px, 안쪽 선(옷 주름·이목구비) 1~2px로 모든 인물이 같게 한다. 투명 바탕 위에서도 윤곽이 배경과 섞이지 않게 바깥 윤곽을 닫는다.
- 아이콘(128×128)은 형태를 크게 잡고 세부를 줄인다. 32px로 줄여 보여도 무엇인지 읽혀야 한다.

## 4. 인물 구도

- **sprite**(회의 화면용, 사람마다 1장): 512×1280 전신, 바탕 투명. 기준선은 `spec.md` 6절이다.
  - 눈높이는 모든 인물이 같은 y≈200, 허리선 y=640, 발끝 y=1248. 키 차이를 크게 두지 않는다(크기·위치로 인물이 튀지 않게).
  - 평소 화면은 머리~허리(0~640행)만 보이고, 전신 컷(첫 등장, 추방·처형 결과, 엔딩, 밤 습격 결과)에서 전신이 보인다. 상반신에 인물 구분 요소(얼굴·머리·윗옷)를 모아 둔다.
  - 같은 자세(정면 또는 약간 돌린 정면). 기본(평상시) 표정은 평온하게 1개다. 들고 있는 소품을 더하지 않는다. 역할을 암시하는 새 소품을 넣지 않는다(6절 4번).
  - 엔딩도 같은 그림을 쓴다. 정체는 글로만 밝힌다(정체별 그림을 만들지 않는다).
  - 생성: 그림에 없는 단색 바탕으로 만들고 투명 바탕 처리(A-08-04)로 알파를 만든다. 실패하면 불투명 흉상 액자식으로 대체한다(`spec.md` 7절).
- **표정 변형**(첫 플레이 8명, 기쁨·당황·슬픔): 기본 sprite를 편집해 **얼굴 영역(`spec.md` 6절, x 160~351·y 104~311)만** 바꾼다. 몸·옷·머리 장식·자세·외곽은 기본과 같다(자동 검사). 얼굴은 표정이 서로 구별되게 하되 과장된 악역 표정, 일그러짐, 눈물·땀 같은 얼굴 밖으로 나가는 효과는 쓰지 않는다. 같은 표정은 인물이 달라도 같은 정도로 그린다(누구는 더 수상하게 당황하는 식 금지, 6절 4번). 눈썹이 앞머리 위로 비치거나 붙여 넣은 경계가 보이면 탈락.
- **마스코트**(까치 `kkachi`, 족제비 `jokjebi`): 512×512, 바탕 투명, 표정 1개. 같은 반실사 화풍으로 그린 동물이며 사람처럼 옷을 입히지 않는다. 몸 전체가 보이게 가운데에 두고, 화면에서 0.5배로 줄어도 형태를 알아볼 수 있어야 한다. 특정 인물·장소를 가리키거나 바라보는 구도, 글자·상징 소품을 넣지 않는다(6절 4번).
- **초상**: sprite 위 512×512를 먹남 위에 합성한 흉상이다. 따로 그리지 않는다. 표정 변형의 초상도 같은 방식으로 파생한다. 얼굴이 가운데에 와서 원형으로 잘라도 얼굴이 잘리지 않아야 한다.
- 모든 인물은 같은 눈높이·머리 크기로 그려, 나란히 놓았을 때 크기가 튀지 않게 한다.
- **느낌**: 머리를 실제 비율보다 조금 크게, 눈은 크고 또렷하게(하이라이트 1~2점), 코·입은 단순하게. 앞머리·옆머리는 눈썹·눈 위에 겹친다(눈썹 선이 머리카락 위로 비쳐 나오면 탈락). 볼 홍조, 반짝이 효과는 쓰지 않는다.
- **주인공(무당)**: 여 `mudang_f`·남 `mudang_m` 2종, 30대, **약간 미화**(정돈된 이목구비, 단정한 무복). 두 버전은 같은 무복 계열·같은 구도로 맞춘다.
- **주민**: 미화 없이 평범하고 자연스럽게 그린다. 직업과 나이는 옷·머리·소품으로 드러낸다(훈장은 갓·서책, 대장장이는 앞치마, 주모는 쪽머리·비녀 등). 기본 표정은 평온한 표정 하나로 통일하고, 표정 변형이 있는 인물도 위 규칙(얼굴만)을 따른다.
- **주인공과 주민의 차이(검수 판정표)**: sprite·초상마다 아래 항목을 본다. 주민은 **모두 같은 열**을 따라야 한다. 주민 한 명만 주인공 쪽 처리를 받으면, 그 인물이 특별하다는 새 게임 정보가 되므로 탈락이다(6절 4번).

  | 항목 | 주인공(`mudang_f`, `mudang_m`) | 주민(전원 같게) |
  |---|---|---|
  | 눈 하이라이트 | 눈마다 2점(큰 점 + 작은 점) | 눈마다 1점 |
  | 이목구비 대칭 | 좌우 대칭 | 자연스러운 작은 비대칭 허용 |
  | 피부 표현 | 매끈함. 주름·잡티 없음 | 나이를 보이는 주름·팔자선을 옅게 허용 |
  | 머리카락 | 정돈된 윤곽 | 흐트러진 잔머리 허용 |
  | 옷 | 무복이 단정함 | 직업 옷. 해짐·얼룩을 옅게 허용 |
  | 공통 | 머리 크기·눈높이·얼굴 비율은 모두 같다. 우스꽝스러운 과장(6절 5번)은 주민에게도 금지 | 같음 |

- 시대는 조선 후기 마을 분위기의 창작 설정이다. 고증보다 인물 구분과 일관성을 우선한다.

## 5. 배경 처리

- **초상·아이콘**: 먹남 단색 배경. 배경에 소품이나 풍경을 그리지 않는다. 초상의 먹남 바탕은 sprite 투명 부분을 합성한 것이다.
- **sprite**: 바탕 투명(위 4절). 반투명 가장자리 픽셀의 색은 인물 색이어야 하고 생성 때 바탕색이 섞여 테두리로 남으면 안 된다.
- **장면 배경**(`spec.md` 7절): 회의 장소 1장과 밤 마을 1장, 1280×720, 완전 불투명. 인물을 그리지 않는다(sprite를 위에 얹는다). sprite가 서는 가운데(x 384~896)는 단순하게 두고, 대사창이 덮는 아래 180px에는 중요한 그림을 두지 않는다. 회의 배경은 낮 마을 마당의 일반 구도, 밤 배경은 어두운 하늘과 지붕선이다. 특정 집·장소·인물을 조명·색으로 강조하지 않는다(6절 4번).
- **지도**: 위에서 내려다본 평면 지도(시연까지 임시 에셋). 장소 5곳(우물가, 서낭당, 주막, 마을 어귀, 집)이 서로 구분되게 놓되 **이름 글자는 넣지 않는다**(화면이 쓴다).
- **광고 소재**: 대상 사물 하나와 단색·단순 배경이다. 소재 제목·본문·"광고" 표시는 화면이 쓰므로 그 자리를 비운다(728×90은 오른쪽 2/3, 300×250은 아래 1/3).

## 6. 금지 요소

모든 파일에 아래가 하나라도 있으면 탈락이다(에셋5 체크리스트).

1. **실존 인물**의 얼굴·이름을 닮게 그린 것. 반실사라 닮을 위험이 크므로 sprite마다 따로 확인한다(8절).
2. **상표·로고**, 실존 상호·브랜드를 떠올리게 하는 표식. 생성 도구의 **워터마크·서명**도 포함한다.
3. **글자**: 한글·한자·영문·숫자, 글자처럼 보이는 무늬·가짜 문자.
4. **새 게임 정보를 주는 표현**: 씐 자·창귀를 암시하는 표정·눈빛·색·그림자·소품, 특정 인물만 다르게 그린 조명·구도·크기, 범행 장소를 암시하는 지도 표시, 특정 장소를 강조한 장면 배경.
5. **외모를 우스꽝스럽게 깎아내리는 묘사**(과장된 추함, 신체 비하). 외모로 창귀가 짐작되지 않게 한다.
6. 설화 원전의 그림·문장을 그대로 옮긴 것(창작만 쓴다).
7. 선정적·잔혹한 묘사. 실종·감금·처형 장면도 상징 소품으로만 그린다.

## 7. 같은 화풍 유지(생성 기록)

반실사 그림은 생성할 때마다 화풍이 흔들리므로, 아래를 생성 기록(`SOURCES.md`)에 남기고 모든 인물에 같게 쓴다.

1. **같은 화풍 프롬프트**: 화풍·빛·선·채색을 적은 공통 문장을 하나 정해 모든 sprite·배경에 그대로 붙이고, 인물마다 다른 부분(옷·머리·나이)만 바꾼다.
2. **시드**: 시드를 고정할 수 있는 도구면 같은 시드를 쓰고 기록한다. 같은 시드로 다시 만들면 같은 그림이 나와야 한다.
3. **기준 그림**: 처음 합격한 sprite 1장을 기준 그림으로 정해, 다른 인물을 만들 때 참고 이미지로 넣는다(도구가 지원하면).
4. **투명 바탕 처리**: 바탕색, 처리 도구·설정(A-08-04)을 적는다.
5. **표정 변형 순서(처음부터 새로 생성 금지)**: 기본 sprite 확정 → **그 파일을 편집 도구의 입력으로 사용** → 얼굴 영역만 변경 → 편집 결과의 얼굴 영역만 기본 sprite에 붙여 넣어 저장 → 초상 파생(`make_placeholders`). 생성 기록에 표정 파일마다 편집 입력(기본 sprite 경로·커밋)과 편집 지시문을 적는다. manifest의 `edited_from`·`edited_from_sha256`이 이 연결을 기록한다(`spec.md` 4절).
6. **기본을 다시 만들면 표정도 다시**: 기본 sprite가 검수 탈락 등으로 바뀌면 그 인물의 표정 3장을 새 기본에서 5번 순서로 다시 만든다(`edited_from_sha256`이 달라 자동 검사가 실패한다).

## 8. 검수 체크리스트

자동 검사(`spec.md` 6절: 크기, RGBA, 가운데, 머리 위 여백, 발끝, 배경 불투명, 용량, 초상 파생)를 통과한 뒤 사람이 본다. sprite와 파생 초상을 모두 본다.

- [ ] 반실사 일러스트 화풍이고 다른 인물과 같은 화풍이다(사진·3D·수채 아님).
- [ ] 빛이 왼쪽 위에서 온다.
- [ ] 선 굵기가 다른 인물과 같다(2절).
- [ ] 색이 기준 색과 크게 다르지 않고, 특정 진영을 암시하는 색이 없다(3절).
- [ ] 눈높이가 y≈200, 허리선이 y=640 근처다(다른 인물과 나란히 놓고 본다).
- [ ] 실존 인물과 닮지 않았다.
- [ ] 6절 금지 요소가 없다(글자, 로고·워터마크, 새 게임 정보, 비하, 원전 복제, 선정·잔혹).
- [ ] 판정표(4절): 주인공·주민 처리가 맞고 주민은 모두 같은 열이다.
- [ ] 가장자리 색 번짐이 없다: 밝은 바탕·어두운 바탕·회의 배경 위, 평소(0.8배)·전신 컷(0.5배) 축소에서 본다(`preview_vn`).
- [ ] 초상(먹남 합성 크롭)에서 얼굴이 가운데에 있고 잘리지 않는다.
- [ ] 표정 변형: 기본과 나란히 놓고 같은 인물로 보이며, 네 표정이 서로 구별되고, 붙여 넣은 경계·앞머리 관통이 없고, 역할을 암시하는 과장이 없다(4절).
- [ ] 마스코트: 밝은·어두운·회의 배경 위와 0.5배 축소에서 외곽 전체가 투명 처리돼 있고 형태를 알아볼 수 있으며, 인물·장소를 가리키지 않는다(4절).
- [ ] 생성 기록에 프롬프트·시드·기준 그림·투명 처리 설정이 있고, 표정 변형은 편집 입력 기본 파일이 적혀 있다(7절).
