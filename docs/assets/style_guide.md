# 에셋 스타일 가이드 (E-05-05)

모든 이미지 에셋(초상, 장면 배경, 장소·UI 아이콘, 지도, 광고 소재, 발표용 이미지)이 따르는 그림 기준이다. 파일 형식·크기·이름·도트 격자는 [`spec.md`](spec.md)를 따른다. 11/11 일괄 검수(E-11-10, 검수자 E)는 이 문서의 항목으로 판정한다.

- 상태: 화풍·변형·팔레트는 PM 결정(11/4). **검수자 B 확인 대기.**
- 제작은 생성형 AI로 한다. 생성 도구는 아직 정하지 않았다(P-10). 진짜 에셋은 생성 도구를 정한 뒤 만든다. 이 문서는 특정 도구에 기대지 않고, 도구별 프롬프트 문법은 생성 기록(`SOURCES.md`)에 남긴다.
- 임시 초상(E-05-05)은 Claude가 코드로 그린 도트 그림이다. 이 문서의 격자·팔레트·외곽선을 따르지만 검수 대상은 아니다(`spec.md` 5절).
- 마스코트·로고(P-21)와 기색 표정 변형(P-20)은 결정 대기라 다루지 않는다.

## 1. 화풍

**도트(픽셀 아트), 외곽선 있음.** 초상·아이콘·지도·광고 소재 전부에 같은 화풍을 쓴다(11/4 PM 결정, 같은 날 만화풍 평면 채색에서 변경).

- 원본 격자에 픽셀 단위로 그린 뒤 정수 배율 최근접 확대로 파일 크기에 맞춘다. 격자는 초상 128×128(×4), 장소·UI 아이콘 32×32(×4), 지도 320×180(×4), 광고 182×22·75×62(×4)다(`spec.md` 6절).
- 안티에일리어싱, 그러데이션, 반투명 픽셀, 디더링 남용, 흐림을 쓰지 않는다. 한 픽셀은 3절 팔레트의 한 색이다.
- 사진풍, 3D 렌더, 수채·유화 질감을 쓰지 않는다.

## 2. 외곽선·명암

- 외곽선은 1픽셀 먹색(`#26231F`)으로 그린다. 인물·사물의 바깥 윤곽과 큰 면의 경계에 둔다. 눈·눈썹·입 같은 얼굴 요소도 같은 먹색을 쓴다.
- 명암은 기본색 + 그림자 1단(필요하면 하이라이트 1단)으로 끊는다. 빛은 모든 에셋에서 **왼쪽 위 한 방향**이고, 그림자는 오른쪽 아래에 둔다.
- 그림자 색은 아래 팔레트의 "그림자" 값을 쓴다. 검정을 섞어 새 색을 만들지 않는다.
- 32×32 아이콘은 형태를 크게 잡고 세부를 줄인다. 32px로 표시해도(1배) 무엇인지 읽혀야 한다.

## 4. 인물 구도

- **느낌: 애니메이션 캐릭터 같은 고해상도 도트**(11/4 PM 요청). 모든 인물에 같은 방식을 쓴다.
  - 머리(얼굴+머리카락)를 실제 비율보다 조금 크게 잡아, 얼굴이 격자 폭의 40~50%를 차지하게 한다.
  - 눈은 크고 또렷하게 그린다(세로 8~12픽셀, 먹색 눈동자 + 백 하이라이트 1~2점). 코는 피부 그림자 2~4픽셀, 입은 짧은 선이나 작은 면이다.
  - 머리카락은 큰 덩어리로 나누고 머리 하이라이트 띠를 1줄 넣는다. 잔머리·한 올 단위 묘사는 하지 않는다.
  - 앞머리·옆머리는 눈썹·눈 위에 겹친다(머리카락을 얼굴 요소보다 앞에 그린다). 눈썹·속눈썹 선이 머리카락 위로 비쳐 나오면 탈락이다.
  - 명암은 셀 2단(기본 + 그림자)이다. 볼 홍조, 반짝이 효과는 쓰지 않는다.
- **초상**: 128×128 격자의 흉상(가슴 위)이다. 정면 또는 약간 돌린 정면이고, 얼굴이 격자 위쪽 1/3~1/2에 오며 머리 위에 4~8픽셀 여백을 둔다. 원형으로 잘라도 얼굴이 잘리지 않게 가운데에 둔다.
- 모든 초상은 같은 눈높이·머리 크기로 그려, 나란히 놓았을 때 크기가 튀지 않게 한다.
- **주인공(무당)**: 여 `mudang_f`·남 `mudang_m` 2종, 30대, **약간 미화**(정돈된 이목구비, 단정한 무복). 두 버전은 같은 무복 계열·같은 구도로 맞춘다.
- **주민**: 미화 없이 평범하고 자연스럽게 그린다. 애니메이션 느낌(큰 눈, 단순한 이목구비)은 주인공과 같게 쓰고, 미화 여부는 이목구비의 정돈 정도로만 구분한다. 직업과 나이는 옷·머리·소품으로 드러낸다(훈장은 갓·서책, 대장장이는 앞치마, 주모는 쪽머리·비녀 등). 표정은 평온한 기본 표정 하나로 통일한다.
- **주인공과 주민의 차이(검수 판정표)**: 검수자는 초상마다 아래 항목을 본다. 주민 초상은 **모두 같은 열**을 따라야 한다. 주민 한 명만 주인공 쪽 처리를 받으면, 그 인물이 특별하다는 새 게임 정보가 되므로 탈락이다(6절 4번).

  | 항목 | 주인공(`mudang_f`, `mudang_m`) | 주민(전원 같게) |
  |---|---|---|
  | 눈 하이라이트 | 눈마다 2점(큰 점 2×2 + 작은 점 1×1) | 눈마다 1점(큰 점 2×2) |
  | 이목구비 대칭 | 좌우 대칭 | 1픽셀 안의 비대칭 허용 |
  | 피부 표현 | 피부·피부 그림자 2색만. 주름·잡티 없음 | 나이를 보이는 주름·팔자선을 피부 그림자색 1~2줄까지 허용 |
  | 머리카락 윤곽 | 계단이 고른 매끈한 윤곽, 하이라이트 띠 1줄 | 하이라이트 띠 1줄. 윤곽의 들쭉날쭉함 허용 |
  | 옷 | 무복이 단정함(주름 표현은 그림자 1단) | 직업 옷. 해짐·얼룩 표현은 그림자 1단까지 |
  | 공통 | 머리 크기·눈높이·얼굴 비율은 모든 초상이 같다. 우스꽝스러운 과장(6절 5번)은 주민에게도 금지 | 같음 |

- 시대는 조선 후기 마을 분위기의 창작 설정이다. 고증보다 인물 구분과 일관성을 우선한다.

## 5. 배경 처리

- **초상·아이콘**: 먹남(`#2E344A`) 단색 배경. 배경에 소품이나 풍경을 그리지 않는다.
- **장면 배경**(11/5 PM 결정, `spec.md` 7절): 회의 장소 1장과 밤 마을 1장, 320×180 격자. 인물을 그리지 않는다(초상을 위에 얹는다). 초상이 놓일 가운데 아래쪽은 단순하게 두고, 대화창이 덮는 아래 1/4에는 중요한 그림을 두지 않는다. 특정 집·장소·인물을 조명·색으로 강조하지 않는다(6절 4번). 밤 배경은 먹남(`#2E344A`) 계열로 어둡게 하되 팔레트 밖 색은 쓰지 않는다.
- **지도**: 위에서 내려다본 평면 지도(11/5 PM 결정으로 시연까지 임시 에셋). 장소 5곳(우물가, 서낭당, 주막, 마을 어귀, 집)이 서로 구분되게 놓되 **이름 글자는 넣지 않는다**(화면이 쓴다).
- **광고 소재**: 대상 사물 하나와 단색·단순 배경이다. 소재 제목·본문·"광고" 표시는 화면이 쓰므로 그 자리를 비운다(728×90은 오른쪽 2/3, 300×250은 아래 1/3). 격자가 나누어떨어지지 않아 남는 위아래 1px는 배경색으로 채운다(`spec.md` 6절).

## 6. 금지 요소

모든 파일에 아래가 하나라도 있으면 탈락이다(에셋5 체크리스트).

1. **실존 인물**의 얼굴·이름을 닮게 그린 것.
2. **상표·로고**, 실존 상호·브랜드를 떠올리게 하는 표식. 생성 도구의 **워터마크·서명**도 포함한다.
3. **글자**: 한글·한자·영문·숫자, 글자처럼 보이는 픽셀 무늬·가짜 문자.
4. **새 게임 정보를 주는 표현**: 씐 자·창귀를 암시하는 표정·눈빛·색·그림자·소품, 특정 인물만 다르게 그린 조명·구도, 범행 장소를 암시하는 지도 표시, 특정 장소를 강조한 장면 배경.
5. **외모를 우스꽝스럽게 깎아내리는 묘사**(과장된 추함, 신체 비하). 외모로 창귀가 짐작되지 않게 한다.
6. 설화 원전의 그림·문장을 그대로 옮긴 것(창작만 쓴다).
7. 선정적·잔혹한 묘사. 실종·감금 장면도 상징 소품으로만 그린다.
8. 도트 규칙 위반: 안티에일리어싱·그러데이션·반투명 픽셀, 팔레트 밖의 색, 격자에 맞지 않는 픽셀(정수 배율이 아닌 확대).

## 7. 생성형 AI 출력 다듬기

생성 도구가 만든 "도트풍" 이미지는 보통 격자에 정확히 맞지 않고 색이 많다. 파일로 넣기 전에 다음 순서로 다듬는다(도구는 E-08-06에서 정한다).

1. 원본 격자 크기(초상 128×128, 아이콘 32×32 등)로 최근접 축소한다.
2. 3절 팔레트로 양자화한다(가장 가까운 색으로 바꾼다).
3. 흐트러진 외곽선·고립된 픽셀을 손으로 정리한다.
4. 정수 배율 최근접 확대로 파일 크기에 맞춘다(`spec.md` 6절).
5. 생성 기록(`SOURCES.md`)에 생성 설정과 함께 다듬은 단계를 적는다.
