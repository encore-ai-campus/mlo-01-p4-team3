- 완료 조건(아래 4단계를 코드로 구현):
  1. **정답 숨기기**: 합성 전용 캠페인(`syn:`)의 소재 × 지면 × 맥락(승/패 화면)마다 실제 CTR을 정해 `out/ad_truth/<run>.json`(평가 전용)에만 저장. 광고 서버는 이 파일을 읽지 않는다(코드 검사 테스트).
  2. **실제 API 경유**: 가상 사용자(세션 가명 ID)가 **실제 광고 서버 HTTP API**로 광고를 요청하고, 서버가 경매로 고른 광고만 본다(생성기가 광고를 직접 고르지 않음).
  3. **주사위**: 받은 광고의 숨긴 CTR로 클릭 여부를 무작위 결정. 같은 사용자가 같은 소재를 반복해서 보면 CTR이 떨어지는 **피로 효과**(감소율을 설정값으로, 정답 파일에 기록). 노출 비콘은 가시 기준을 만족한 경우만 보냄.
  4. **무효 클릭 주입**: 기본 5%(검증 시나리오 설정값이며 기획서 수치가 아님. 0%·20%로도 실행해 무효 과금 0건 확인). 전체 클릭의 해당 비율을 무효 유형(같은 serve 중복 클릭, 노출 없는 클릭, 만료·위조 토큰, 빠른 연속 클릭)으로 섞고 유형별 수를 정답 파일에 기록.
  5. `source=synthetic`, 합성 캠페인만 가리킴(`tests/contract/test_ads.py::SyntheticAds` 통과). 시드 고정 재현.
