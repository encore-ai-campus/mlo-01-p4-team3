  4. 참가자 안내: 지원 브라우저는 최신 크롬·엣지로 한정한다. 첫 접속 때 브라우저 경고를 한 번 넘기는 방법(크롬·엣지 문구)과 대조용 인증서 지문(SHA-256)을 `ops/proxy/README.md`에 쓰고 E에게 넘긴다(사전·정식 사용자 테스트 안내에 사용). 서버가 아닌 다른 노트북 1대에서 경고 넘기기 → wss 연결(101)까지 확인한다. 경고를 넘길 수 없는 기기(관리 정책으로 막힌 브라우저 등)는 Caddy 내부 루트 인증서를 그 기기에만 설치하는 방법을 대안으로 적는다.
