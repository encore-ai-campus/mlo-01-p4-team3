# 개인정보 계약 (B 수집, C 저장·삭제, D·E 사용)

기획서 8.5는 아직 가정 단계다. 아래 내용은 사용자 테스트 전에 PM이 확정한다.

## 1. 식별자
- 실명, 연락처, 계정 ID는 게임 데이터에 저장하지 않는다. 참가자 명단(연락처)은 PM이 저장소 밖에서 따로 관리한다.
- 플레이어는 **가명 ID**(`player_pseudonym`)로 식별한다. 첫 접속 때 무작위 UUID를 발급하고 쿠키에 저장한다. 이 ID와 실제 인물의 대응표는 만들지 않는다.
- 세션 ID(`session_id`)는 테스트 회차를 묶는 용도로만 쓴다.

- 광고는 세션 가명 ID만 받는다. 플레이어 가명 ID와 판 내용은 광고 서버에 보내지 않는다(ads.md 9절). 광고 이벤트도 같은 보존·삭제 규칙을 따른다.

## 2. 원문 텍스트(자유 입력, 설문 의견)
- 저장 전에 마스킹한다. 전화번호, 이메일, 주민번호 형식, 13자리 이상 숫자열을 `<MASK>`로 바꾼다. 마스킹 규칙의 버전도 기록한다.
- **보존 기간**: 원문은 프로젝트 종료일(11/12) + 30일까지 보관한다. 그 뒤 원문은 삭제하고 라벨과 특징만 남긴다.
- **삭제 요청**: 참가자가 가명 ID로 요청하면 그 ID의 이벤트, 원문, 진척 상태를 삭제한다. 이미 학습된 모델은 다음 재학습부터 제외한다. 처리 담당은 C다.

## 3. 수집 고지 문구(시작 화면, 동의해야 진행)
> 이 게임은 연구·수업 프로젝트입니다. 플레이 기록(선택, 입력한 문장, 수첩 값, 설문)을 이름 없이 저장하고, 게임 속 인물의 행동과 입력 해석 모델을 개선하는 데 씁니다. 개인정보(이름, 연락처 등)는 입력하지 마세요. 입력하더라도 자동으로 가립니다. 기록은 2026년 12월 12일까지 보관하며, 화면 아래의 ID로 삭제를 요청할 수 있습니다.

## 4. 학습 사용 범위

| 데이터 | 학습 사용 | 제외 조건 |
|---|---|---|
| 행동 로그(명령, 투표, 수첩) | 씐 자 모델 평가, 대역 봇 보정 | 동의하지 않은 세션, `load_test`, 중단된 판(라벨 없음) |
| 자유 입력 문장 | 의도 해석기 학습·평가 | 마스킹 후에도 개인정보가 남은 문장(검수 때 제외), `auto_executed` 단독 라벨 |
| 설문 | 분석만, 학습 제외 | - |
| 운영 지표 | 학습 제외 | - |

- 학습에 쓰는 행에는 가명 ID를 분할 키로만 남긴다. 특징값에는 넣지 않는다.
