### 첫 화면과 시작 선택

비로그인 `/`는 게임 소개 → 가입/로그인 → 시작 방법 3단계다. 로그인 폼으로 강제 이동하지 않는다. 추가 안내는 사용자 요청에 따른 제품 문구이며 원본 시안의 가짜 계정 경고를 옮기지 않았다.

로그인 뒤에는 일반 게임과 배정된 테스트 참여를 하나씩 펼친다. 미완료 배정이 있으면 테스트가 먼저 열리고 없거나 모두 완료면 일반 게임이 열린다. IAB에서 테스트 선택 시 일반 시작 버튼 `isVisible=false`·테스트 시작 `true`, 일반 선택 시 반대로 확인했다. 배정 판을 실제 시작해 아침 화면을 확인하고 홈으로 돌아와 같은 판 이어 하기를 확인했다. 기존 시작 UUID·세션·프리셋·시드·모습·열린 결말·소유권 정책을 바꾸지 않았다. 새 요청 경로도 없다.
