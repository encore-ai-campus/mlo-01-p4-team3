# A-10-05 장면 배경 2장 (회의·밤)
- 상태: 로컬 구현·증빙 작성 완료. 완료 조건 중 "실제 배경으로 B-10-07 화면 테스트 재실행 통과"만 남았다(B-10-07 병합 전이라 태스크 문서대로 11/11 오전에 실행)
- 작성자(흐름): A
- 담당: E(11/9 PM 결정으로 D에서 변경)
- 작성일: 2026-11-09
- 환경: Windows 11, miniconda Python, 브랜치 task/A-10-05(base origin/dev fdf41d6). 정규화 도구는 표준 라이브러리와 저장소 `tools/assets`만 쓴다. 시안에서 원본을 꺼내고 검수 그림을 만드는 데만 저장소 밖에서 Pillow를 썼다.

## 명령

입력은 B(김영주)가 11/7 팀 공유 폴더에 올린 화면 설계 시안 `2.asset 개선안 및 게임 UI 구성(김영주)/창귀_화면설계_디자인시안.html` 안의 이미지다. 시안의 manifest 키 `background:meeting`(MD5 앞 8자리 9a9cda47)·`background:night`(9d1c47ff)인 1672×941 RGB PNG를 base64에서 꺼내 저장소 밖 작업 폴더에 두고 읽었다. 같은 시안의 `background:dusk-proposal`은 규격 2장 범위 밖이라 쓰지 않았다.

```powershell
python -m tools.assets.normalize --background meeting=<원본 사본> --background night=<원본 사본> --report <저장소 밖 JSON>
python -m tools.assets.check_assets --allow-placeholder place,ui,map,ad
python -m unittest tests.assets.test_normalize
python -m tools.assets.preview_vn --bg meeting --id hunjang --mode normal --mascot kkachi --out <저장소 밖>
python -m tools.assets.preview_vn --bg meeting --id mudang_f --mode full --out <저장소 밖>
python -m tools.assets.preview_vn --bg night --out <저장소 밖>
python -m tools.precheck --with-assets
```

처리 순서: 원본 불투명 확인 → 가운데 기준 정확한 16:9 자르기(16k×9k 중 원본에 들어가는 가장 큰 k, 확대 없음) → 면적 평균 축소(가로·세로 같은 배율) → 1280×720 RGB → `vn.check_background` → 무손실 PNG. 두 장이 모두 통과한 뒤에만 파일·manifest를 쓴다. 같은 입력을 두 번 돌려 같은 SHA-256이 나오는 것을 확인했다.

## 출력

- 실제 경로 덮어쓰기: `content/images/background/meeting.png`, `content/images/background/night.png`
- manifest: `background:meeting`·`background:night` `placeholder: false`(다른 항목 변화 없음)
- 생성 기록: `content/images/SOURCES.md` "A-10-05 실제 에셋" 절. 도구·모델·생성 시각은 원본 PNG의 콘텐츠 자격 증명(C2PA) 값(ChatGPT, gpt-image, 2026-11-06 15:06~15:07 UTC)이다. 서명은 검증하지 않았다
- 코드: `tools/assets/normalize.py`(배경 함수·CLI 추가), `tests/assets/test_normalize.py`(배경 시험 6개 추가, 모두 12개)
- 사람 검수용 그림(저장소 밖 `a1005_review/`): 정규화 배경 2장, 회의 배경 + 훈장 평소 표시 + 까치, 회의 배경 + 무당 여 전신 컷, 밤 배경(인물 없음)
