## 출력

기존 이미지 102개 제공·같은 ID의 실제 파일 교체·회의·8인 녹화 화면 회귀와 신규 지도 시험을 실행했다. 초기 밤 단위 시험은 JSON dict를 dataclass로 잘못 취급해 실패했고 화면 모델로 바꿔 관련 18건이 3.724초에 통과했다. 이름·하단 출처 보완 후 전체 서버는 다음과 같다.

~~~text
Ran 224 tests in 44.660s
OK (skipped=4)
~~~

MySQL 전용·실제 Mongo 조립 등 환경 의존 4건은 건너뛰었다. 실제 DB 재검증 결과로 표시하지 않는다. DB·쓰기 경로 변경은 없다.

Browser plugin not available. 기존 Playwright·설치된 Chrome으로 실제 렌더를 확인했다. 첫 HTTP 전용 미리보기는 웹소켓 404로 실패했고, 운영 코드를 바꾸지 않고 시험용 Daphne로 바꿔 전체 브라우저 절차를 재실행했다. 데스크톱 1280×900·모바일 360×800·CSS zoom 2에서 가로 넘침·이미지 누락·장소 이름 겹침이 없었다. CSS 확대이며 브라우저 고유 확대 기능을 시험했다고 주장하지 않는다. 제목·본문·지도·13종 초상 펼치기/접기·읽기 전후 상태 동일·6인 녹화 완주·종료 후 안내 유지, 콘솔/페이지 오류 0·실패 응답 0을 확인했다. 화면 이미지는 저장소 밖 검수 폴더에 보관했다.

첫 화면 로딩은 로그인 쿠키만 옮긴 새 브라우저 컨텍스트 10개에서 동일 게임을 load까지 열고 Navigation Timing의 loadEventEnd를 읽었다. 초상 목록은 기본 접힘·lazy 상태이며 펼쳤을 때의 추가 로딩은 이미지 decode로 별도 확인했다. 로컬 시험 서버·임시 DB·녹화 엔진 수치이며 VM·실사용 부하·실제 에셋의 성능이 아니다. 서버 회귀와 측정 일부가 겹쳐 호스트 경합을 배제한 벤치마크도 아니다. p95는 nearest-rank 방식이다. 합격 시간 상한은 태스크에 없어 임의로 추가하지 않았다.

[측정 JSON](perf/B-10-02/local_browser.json)은 tools.evidence_result.write_result로 작성했다.
