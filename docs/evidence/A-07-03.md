- 1단계 `tests/engine/test_int07.py`: #2 반례 4종을 규칙 v0 위에서, #1 6인·창귀 1 판 3판 버튼 명령만으로 완주, #3 0·1일째 아침 발표의 피해 장소(엔진 몫).
- 2단계 `server/tests/test_game_factory.py`: 운영과 같은 엔진·의심 모델(`engine_parts`)과 부착 함수(`attach_interactions`)에 메모리 게임·진척 저장소와 시험용 보조 기록 저장을 끼우고, 실제 Django 라우트로 고정 회차 3판을 진행한다. 플레이어 명령은 화면 정보(`PlayerView` JSON)의 합법 명령(`bench_player_command`)만 명령 API로 낸다. Mongo 시험(`PALDO_TEST_MONGO_URI`가 있을 때만)은 B 실행 자원(`open_mongo_runtime`, 고유 접두어) 위에 운영 조립(`build_from_runtime`)을 그대로 해 판을 진행하다 실행 자원을 새로 열어(재시작과 같음) 이어서 끝낸다. 회차도 Mongo 회차 저장소에 등록한다.
- 운영 경로 확인(저장소에 넣지 않은 일회성 스크립트, `manage.py shell`): 시험 설정에 `GAME_SERVICE_FACTORY=server.infra.game_factory.build_game_service`, `SESSION_MONGO_URI`를 로컬 레플리카셋 고유 DB로 두고 `composition.get_game_service()`·`get_session_service()`를 불러 조립 결과를 확인한 뒤 DB를 지웠다. 판 진행은 같은 조립 함수를 쓰는 Mongo 시험으로 확인했다.

## 웹 재현 순서
통합 자리에서 사람이 브라우저로 확인하는 순서다. 서버 준비는 [`docs/modules/web.md`](../modules/web.md) 사용법의 운영 게임 서비스 로컬 실행 1~7번을 따른다(`PALDO_GAME_SERVICE_FACTORY=server.infra.game_factory.build_game_service`).

1. #1 버튼만으로 완주: 운영자가 `/admin/sessions`에서 참가자 가명 ID로 고정 판 3개(`base6`, 시드 3개)를 등록한다. 참가자로 로그인해 홈에서 판을 시작하고, 자유 입력 없이 화면 버튼(넘기기·캐묻기·의심·투표·점)만 눌러 결과 화면까지 간다. 홈으로 돌아가 다음 판을 시작해 3판을 끝낸다. 오류 화면이 한 번도 나오지 않으면 통과다.
2. #3 피해 장소: 판을 시작한 첫 화면(1일째 아침)에 "1일째 아침: ○○의 짚신이 ○○에서 발견됐다"가 보이는지 확인한다. 2일째 아침까지 간 판에서 "2일째 아침: …" 문장이 함께 보이는지 확인한다.
3. #4 중복·오래된 명령·재개: 버튼을 빠르게 두 번 눌러도 행동이 한 번만 반영되는지, 두 탭에서 같은 판을 열고 한쪽에서 행동한 뒤 다른 탭에서 행동하면 반영되지 않고 충돌(409) 안내가 나온 뒤 최신 화면으로 바뀌는지 본다. 판 도중 서버를 끄고 다시 띄운 뒤 홈에서 같은 판이 이어지는지(같은 날짜·단계·진술표) 확인한다.
4. #6 비공개 정보: 판 3개를 하는 동안 브라우저 개발자 도구 네트워크 탭에서 `/games/…` 응답(JSON·HTML)을 열어 `claim_truths`, `npc_states`, `beliefs`, `private`, `night_plans`를 찾아 0건인지 확인한다.

## 로그
위치: 표준 출력(Django 요청 로그 `game-web`·`http_request`, JSON 한 줄). 로그에는 판 ID·경로·상태·시간만 있고 가명·Mongo 연결 문자열은 없다.

콘텐츠 적재: 적재 도구 `server.infra.load_content`는 `content_bundles`에 쓰고 B 실행 자원은 `content`를 읽어, 로컬 실행 순서 3번은 `content`에 직접 넣는 한 줄 명령으로 안내했다(이름 맞춤은 B·C 확인 대기). 그 명령으로 넣은 뒤 `MongoContentSource(...['content']).load('content-1.0')`이 `content-1.0`을 돌려주는 것을 확인했다.
