### 수명주기 승률 관문 추가 확인

`b4e045d8d11db9369b1e0167fa8bd7ffb6ed5bb05cf1636681719868c7d74db1`다.

2. D-07-02: 통합된 features/evaluate 코드, 신뢰된 배포용 logistic artifact/해시·특징 버전·재현 환경, 최종 Delta 평가 입력/버전. 현재 pkl은 LightGBM 객체도 포함하므로 게임 웹 환경에 그 로드 의존성이 필요하다.
3. D-08-04: 최소 Selector와 모델 인스턴스 버전 고정/이전 버전 보존/close 정책. 이 브랜치는 선택 로직을 구현하지 않는다.

추론 90ms는 고정 주민 수의 로컬 순차 호출에서 시험했다. 큰 메시지나 IPC 도중 멈춘 worker·웹 동시성 전체에 대한 절대 wall-clock 보장은 검증하지 않았다.
근거별 기여값이 없는 산출물은 빈 매핑을 반환한다. 실제 설명 계약/성향 가중 검증도 추가 인계가 필요하다.
