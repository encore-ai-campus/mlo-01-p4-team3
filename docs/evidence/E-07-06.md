- PM 결정(11/6, 원본 E_pm.md 조건 2 문구 변경 대기)
  - 스레드 수는 `min(GEN_SETTINGS["n_threads"], CPU 수)`로 하고, 첫 설정 표에 "GEN_SETTINGS 8 → 실제 N"으로 표시한다. 무료 코랩은 vCPU가 2개다.

  - ⑥의 질문은 화면에 표시만 하고, 반응 의도는 직접 고른다. 기획서 7.2대로 LLM은 사실 문장과 반응 의도만 받는다.
- 참고: llama.cpp는 스레드 수가 달라도 같은 시드에서 출력이 대체로 같다. 다만 부동소수점 합산 순서 때문에 보장되지는 않는다. 코랩 결과에서 E-07-07(8스레드)과 판정이 다른 사례가 보이면 그 수를 적는다.
## 명령
```
# 코드 검사(커밋 전, rebase 뒤 다시)
(for d in engine contract tools ops sim intent llm; do [ -d tests/$d ] || continue; rc=0; python -m unittest discover -s tests/$d -t . || rc=$?; [ $rc -eq 0 ] || [ $rc -eq 5 ] || exit $rc; done)
python -m tools.build_llm_bundle --out out/llm_mvp/a/ && python -m tools.build_llm_bundle --out out/llm_mvp/b/ && sha256sum out/llm_mvp/a/*.zip out/llm_mvp/b/*.zip
python -m tools.check_secrets
python -m tools.check_structure --all
python -m tools.check_docs --diff origin/dev
# 최종 검사: 전체 unittest 중 tests/assets는 이 브랜치에서 바뀌지 않아 제외(메모리 부족으로 전체 실행이 두 번 강제 종료, PM 결정)하고 precheck로 대신
python -m tools.precheck --base origin/dev --pr-body C:/encore_project/4rd_project/pr_E-07-06.md
# 제출 zip(병합 커밋 17d995f에서)
python -m tools.build_llm_bundle --out out/llm_mvp/
# 노트북 시험 실행: 복사본에 LOCAL_MODEL_PATH·LOCAL_ZIP_PATH를 넣고 nbclient로 실행(커널 .venv Python 3.14.6). 평가 세트를 앞 3건, 일관성을 2건 × 2회로 줄인 동작 확인용
```
