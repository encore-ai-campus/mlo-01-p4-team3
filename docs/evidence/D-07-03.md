# D-07-03 BERT 미세조정 시작
- 커밋: 6f5026c56add84f9b881f1a91312882d40e58ad2
- 작성자(흐름): D
- 환경: Windows, Python 3.14.6, torch 2.15.0+cpu, transformers 5.22.1, scikit-learn 1.9.1. CPU float32, intra-op 4·inter-op 1스레드.

## 완료 기준

태스크의 조건 1은 선택한 모델로 미세조정을 1회 완료하고, 계보 단위 분할·기준선과 같은 평가 표·학습 시간·CPU 사용량·모델 파일 보관을 증빙하는 것이다. “1회”는 실행 횟수이며 epoch 수는 지정되어 있지 않다. 1·3·5 epoch는 사용자가 요청한 비교 실험의 설정이다.

## 명령

원본 280행과 생성 변형 252행을 포함한 총 532행을 사용했다. 생성 변형은 사용자 요청에 따라 `--include-generated`로 포함했다. 파일의 출처 표시는 유지했으며 미검수 변형을 포함한 개발 실험으로 기록한다. 계보·대조쌍 단위로 학습 390행과 평가 142행을 분리했다.

```powershell
$py = 'C:/mlo-01-p4-team3/.venv/Scripts/python.exe'
& $py -X utf8 -m tools.perf.intent_finetune --data content/intent/examples_v1.jsonl --cache C:/mlo-01-p4-team3/out/hf_cache --epochs 1 --batch 4 --length 64 --threads 4 --seed 7 --include-generated
& $py -X utf8 -m tools.perf.intent_finetune --data content/intent/examples_v1.jsonl --cache C:/mlo-01-p4-team3/out/hf_cache --epochs 3 --batch 4 --length 64 --threads 4 --seed 7 --include-generated
& $py -X utf8 -m tools.perf.intent_finetune --data content/intent/examples_v1.jsonl --cache C:/mlo-01-p4-team3/out/hf_cache --epochs 5 --batch 4 --length 64 --threads 4 --seed 7 --include-generated
& $py -X utf8 -m tools.check_evidence D-07-03 --complete
& $py -X utf8 -m tools.check_docs --task D-07-03
```

## 출력

최신 dev 반영 후 PR 본문 초안으로 실행한 전체 사전 검사 결과다. 출력은 `out/d07_03_submission/precheck.txt`에 있다.

```text

```

모든 실험은 같은 사전학습 revision에서 시작했다. 배치 4, 길이 64, CPU 스레드 4, AdamW(lr=2e-5), seed 7, 임계값 0.20을 사용했다. 두 데이터 분할의 ID와 비교 기준선의 개별 예측이 세 실행에서 같은지 검증했다.
