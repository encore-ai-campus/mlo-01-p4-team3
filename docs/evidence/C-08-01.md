# C-08-01 Prometheus·Grafana·경보

- 커밋: 32fbf56
- 작성자(흐름): C
- 환경: PJ4 테스트 VM의 Prometheus·Grafana, TLS 검증을 켠 Chrome
- 상태: 부분 완료. MySQL03 VM 수집은 미완료다.

대시보드 6종과 경보 6개를 구성했다. 합성 검증 실행 r6에서 활성 판 30개를 유지하는 동안 6개 화면을 모두 캡처했다. 전체 30판이 끝났고 HTTP 303건 중 오류 0건이었다. 부하 도구의 HTTP 동시 실행 상한은 12였다. 브라우저의 대기 시간을 포함한 클라이언트 p95는 4048.847ms이고, 서버 미들웨어 실측 p95는 1152.402ms로 1초 기준을 초과했다.

이 캡처 뒤 광고 패널을 P-25 집계 정의에 맞췄다. 캠페인·귀속일 소진율과 전체·지면별 fill, 노출·클릭 무효율은 source 및 잠정·확정 라벨을 유지한다. 캡처의 광고 화면은 이 변경 전 버전이다. 운영 런타임 LLM은 P-31 결정에 따라 사용하지 않아 해당 패널에 실측값이 없다.
