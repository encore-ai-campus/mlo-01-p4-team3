엔진 대조로 고친 점:
1. 투표: 서버 설정으로 고르는 기권 허용 규칙(`rule-0.9`, 기본은 `rule-0.8`)을 2.2에 추가. 마을 NPC는 상위 두 후보 점수 차 0.05 이하이면 기권, 씐 자는 기권 안 함, 전원 기권이면 무감금(`engine/domain/params.py`).
2. 한밤 집 동선 가중치 ×0.25를 3.2에 명시(`rule-0.8`).
3. 공개 프리셋: 서비스 공개는 기본 6인(`server/app/presets_enabled.json`)을 1.1·3.1에 명시.
4. 콘텐츠 수량: 주민 풀 8명(성향 4종 × 2명), 비밀 7, 원한 단서 4, 템플릿 47, 장소 5, 결말 2(`content/bundle_v1.json`, `content-1.1`)로 4.3·10장 수정.
5. 의도 해석기 운영 모델은 TF-IDF + 로지스틱 회귀 기준선이고 BERT 계열은 비교 후보(1.1·5.1·8.1).
6. 씐 자 확률 모델 운영은 로지스틱 회귀 웹 프로세스 직접 추론, LightGBM은 비교 모델(1.1·5.1·8.2).
7. 가명 대응표 저장소를 MongoDB로 표기(5.4, `server/infra/test_sessions.py`). 이미지 에셋 행은 `content/images/manifest.json` 기준(실제 sprite·초상·지도·광고 소재, 임시는 장소·UI 아이콘과 확장 주민 3명).
