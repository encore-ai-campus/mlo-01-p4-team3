- 판 종료 전 `GET /games/{id}/review`(htmx)는 403이고 비밀 문안이 없다. 종료 뒤에는 `review_panel.html` 조각(문서 전체 아님)으로 주민 정체(무당 제외, 씐 자 먼저)·숨긴 비밀 제목·이 판에서 얻은 단서만 보인다. 다른 판에서 얻은 단서와 비공개 진술 ID는 없다. `review_side` 지면 1개, `Cache-Control: private, no-store`, 판 문서 불변, JSON 요청의 `ReviewOutput` 키 유지(`test_review_fragment_after_end_only`).

## 복기 광고 PC 배치 후속 검증

2026-11-12, dev `eea9657` 기준으로 B가 판 종료 복기 탭의 배치를 확인했다. B-10-01의 넓은 화면에서 본문 옆, 좁은 화면에서 본문 아래 조건을 `result.css`에 반영했다. Chrome에서 실제 규칙 판의 주민 정체와 행동 기록을 열고, 등록된 소재를 시험 광고 응답으로 제공했다.

| 확인 | 결과 |
|---|---|
| PC 1528px·900px | 복기 본문 오른쪽에 `review_side` 1개, 이미지 300×250px |
| 폭 899px·390px | 복기 본문 아래, 이미지 300×250px |
| 폭 320px | 복기 본문 아래에서 272×226.7px로 비율 유지 |
| 복기와 광고 동작 | 같은 판에서 탭 전환·복기 재시도·같은 출처 광고 클릭을 확인했다. 빈 소재 응답에서는 본문이 전체 폭을 썼고 원한 단서·공개 기록·설문에는 광고가 표시되지 않았다. |
| 노출 비콘 | 1528px·390px 모두 이미지가 50% 이상 1초 이상 보일 때 시험 제공자로 한 번 중계됐다. 탭 재진입 시 같은 소재의 비콘 중복은 0건이었다. |

Chrome의 다섯 화면 크기에서 가로 넘침과 JavaScript 예외는 0건이었다. 복기·판 종료·광고 지면·에셋 Django 회귀 시험은 23건 통과했다.

```text
python -B -m django test server.tests.test_review server.tests.test_game_end server.tests.test_ad_slots server.tests.test_assets --settings=server.paldo_web.test_settings --verbosity 0
Ran 23 tests in 3.760s
OK
```

원자료는 저장소 밖 `UI_재설계_검토/B-10-01_복기광고_배치검수/`의 `review-ad-final.log`, `django.log`, PC·모바일 캡처에 보관했다. 이번 기록은 복기 탭의 광고 배치 확인이며 전체 태스크 판정은 [B-10-01](../tasks/E_pm.md#b-10-01-복기-화면)을 따른다.
