# E-05-01 저장소·결정 기록·담당 배정·이슈 생성
- 커밋: bd950ae
- 작성자(흐름): E
- 환경: GitHub(교육기관 조직 저장소, 비공개, 무료 플랜), gh CLI, 로컬 Windows 11
## 명령
```
gh api repos/<OWNER/NAME> -q '{private,visibility,default_branch,allow_merge_commit,allow_squash_merge,allow_rebase_merge}'
gh api repos/<OWNER/NAME>/branches/dev -q .commit.sha
gh api repos/<OWNER/NAME>/branches/main -q .commit.sha
gh api repos/<OWNER/NAME>/branches/dev/protection
python -m tools.tasks_to_issues --dry-run
python -m tools.tasks_to_issues --apply --repo <OWNER/NAME>            # 11/5 담당 변경·범위 축소 반영 뒤 재동기화
python -m tools.tasks_to_issues --apply --repo <OWNER/NAME> --assign A=Ducks-Lee,B=escapedaily99,C=gururr-lab,D=LEEHYUNGIN,E=Ducks-Lee   # 담당자 확정(P-01) 뒤
gh issue list -R <OWNER/NAME> --state all --limit 300 --json state,stateReason,assignees
```
(`<OWNER/NAME>`은 README 3절의 저장소. 저장소 주소는 비밀이 아니지만 명령 기록 형식을 통일하려고 자리 표시로 둔다)
