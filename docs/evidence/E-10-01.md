## 출력

```text
tests.llm.test_review_narration: 20 tests OK (위반 예시 22개 전부 거부)
server.tests: Ran 475 tests, OK (skipped=14)
seq 1..12: done, gen 26.6~37.1s / burst 4판: done, 마지막 판 대기 90.0s + 생성 31.9s
```

- 위반 예시 표(`ViolationTable`, 22개): 인용 밖 인물·장소, 행동 반대(감쌌는데 의심·투표 대상 바꿈·부정형), 없는 날짜, 원인 표지로 만든 인과("~때문에", "~해서"), 형식(끝맺음·길이·나열·같은 낱말 반복) 모두 거부.
- 서버 시험(`server/tests/test_review_narration.py`, 14개): 기능 꺼짐이면 등록·호출 없음과 Kanana 표기 숨김, GET 멱등 등록, 판 진행 중 403·호출 없음, 대기 10건 넘으면 과부하로 템플릿, 임대 만료 뒤 재처리, 늦게 온 결과 버림(토큰·마감 조건부 완료), 판 삭제 시 `review_jobs` 삭제, 생성기 오류·시간 초과·응답 깨짐이면 템플릿, NPC별 부분 대체, 2초 폴링 조각(생성 중 문구, 확정 뒤 폴링 멈춤).
- Chrome 1528×730(저장소 밖 `review_llm_screens/`): 복기 탭을 열면 "마을 사람들의 속마음" 아래 "족제비가 해설을 다듬고 있어요…"가 먼저 보이고(1), 작업이 끝나면 같은 자리에 검사를 통과한 NPC 문장만 바뀌어 보인다(2, 판 생성 24.2초). 생성 서버에 닿지 않으면 작업이 실패로 끝나고 묶음이 숨겨지며 템플릿 해설 타임라인만 남는다(3). 판 화면 좌측 하단 출처 영역 첫 줄에 "Powered by Kanana" 1곳, 글자 크기 13.6px로 다른 출처 줄과 같다. 홈·로그인 화면에는 없다.
