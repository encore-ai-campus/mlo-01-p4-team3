실제 의도 실행에는 위 스크립트에서 `--fixture`를 빼고 동결본의 `--data-version freeze:<manifest sha256>` 또는 C가 확인한 `delta:<table>@<version>`을 넣는다. 첫 모델은 `--first-model`로 기존 의도 기준선을 비교한다. 운영 BERT 체크포인트가 있으면 `--reference-bert`로 그 경로를 지정한다. `--out`에는 승인된 비공개 경로를 사용하고, 등록 방식은 격리 `--registry-dir` 또는 C 실행기에 등록을 맡기는 `--report-only` 중 하나를 고른다.

E 검수 라벨은 `IntentExample` JSONL이고 `example_id`는 동결 파일의 `attempt_id`와 같다. 학습은 `split=train`으로, 평가 전체는 `split=test_human`과 `label_source=human_annotation`으로 넘긴다. 평가 맥락 JSONL은 `example_id`, 당시 공개 `ParseContext`의 `context`, 독립 정답 `commands` 배열을 받는다. 미지원은 빈 정답 배열이다. 양쪽 평가에 같은 검수 자료를 사용하며 비교에 필요한 미지원 또는 대조쌍이 없으면 관문에서 거부한다.

정식 테스트 중 매 정각에는 승인된 Spark 호스트에서 `python -m pipeline.spark.ut_bronze_counts --config <C 설정> --out <시간별 출력 파일>`을 실행한다. 18:00 마감에는 `python -m tools.ut_freeze`를 기본 cutoff로 실행해 정식·사전 테스트 내보내기, PM 가명, 시드, 학습·개발 제외 세트, 개인정보 검수 입력을 지정한다. 동결 manifest와 두 분할을 E가 확인한다. E의 판정과 인계 예정은 19:30 KST다.

## 출력

11/11 실데이터 결과는 위 절의 표다. 아래는 11/10 합성 리허설 출력이다.

합성 동결은 8명을 평가 4명과 학습 4명으로 분리했다. 사용자·문장 중복은 각각 0건이었다. 동결 뒤 등록한 삭제 가명 1명의 라벨 행 2개를 빼고, `auto_executed`를 거른 뒤 합성 학습 문장 3개를 추가했다.

KoELECTRA를 CPU에서 1epoch 재학습하고 체크포인트를 BERT 해석기로 재로딩했다. 같은 합성 평가 8문장의 명령 일치율은 후보 50%, 기준선 100%였다. D 관문 거부 사유는 격리 MLflow의 `paldo.gate.reasons`에 남았고 등록 버전은 0개였다. C 관문도 합성 데이터 버전에 `required_run_metadata`를 기록했다. 실행 시간은 179.777초였다.

별도 격리 DB에서는 네이티브 체크포인트 경로의 후보 등록과 재시도를 시험했다. 같은 run과 아티팩트를 두 번 등록한 결과 같은 후보 버전 1과 같은 run ID가 조회됐다.

보정 봇으로 base6 450판을 재생성했다. 26,363개 후보 행을 생성해 316판을 학습에 사용했다. 같은 시드의 별도 벤치마크 50판에서 후보/기준선 로그 손실은 0.8347/1.0066, 후보 ECE는 0.03595였다. 마을 승률은 후보 98%, 기준선 92%로 차이 6%p였고, 사람 평가도 없어 후보를 거부했다. SQLite 첫 실패 뒤 검증된 행부터 학습·관문을 이어 실행했으며 재개 구간은 56.268초였다.

격리 카나리아는 이전 규칙 모델을 두 버전에 사용했다. 카나리아 30판과 대조 138판의 마을 승률은 90.00%와 92.75%였다. 양쪽 표본을 충족한 뒤 시험 레지스트리에서 `production`을 2로 변경했다. 모델 예외를 주입하자 폴백률은 100%가 됐다. `production`을 1로 돌리고 새 판은 1을 선택했으며, 앞서 시작한 판은 2로 명령을 계속 처리했다. 봇 판의 의도 수정·취소율은 측정 불가였다.

### 11/11 C-10-01 연동 실증

D의 격리 실증을 C의 `transition`과 `MlflowModelRegistry`, B의 `VersionPinning`으로 실행했다. 카나리아 30판과 대조 116판을 완료했다. 시험 레지스트리의 운영 별칭이 버전 2가 된 뒤 모델 실패를 주입했고, C 롤백으로 새 판은 1을 선택했다. 앞서 시작한 판은 버전 2로 명령을 계속 처리했다. 복구 사유 태그와 카나리아 별칭 제거도 확인했다. 경보 주입과 승격 경합 시험은 [C-10-01 증빙](C-10-01.md)에 있다.

의도 학습기의 `--report-only`는 체크포인트와 `decision.json`을 만들고 C 실행기가 MLflow 기록을 맡게 한다. 합성 동결본의 manifest 해시를 `freeze:` 버전으로 검증한 뒤 KoELECTRA를 1epoch 실행했다. C의 `record_candidate`가 격리 SQLite에 D 관문 거부를 기록했으며, 등록 모델은 0개였다. 의도 학습·평가 시간은 149.438초다.

~~~sh
python -m ml.lifecycle_demo --out <새 격리 디렉터리>
python -m intent.retrain <동결본·라벨·맥락·삭제 목록 인자> --report-only
python -m ops.mlflow.retrain --config <보호 설정> --check
~~~

실제 Job에는 학습 이미지, 검수 입력 PVC, 최신 삭제 목록, MLflow 접속 설정이 필요하다. 이 실증은 로컬의 합성 입력과 격리 레지스트리에서 D 보고서와 C 등록 함수의 연결을 확인한 것이다.
