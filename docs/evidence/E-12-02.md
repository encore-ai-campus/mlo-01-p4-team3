- 커밋: 1dfb5def3b6eff374fbe754d29683e94c45b9d7e
- 작성자(흐름): E
- 환경: 로컬 Windows 11, miniconda Python. 문서만 바꾸고 코드·운영 설정은 바꾸지 않는다.
## 명령
```
grep -cE 'P-[0-9]{2}' docs/brd.md docs/prd.md
grep -cE '1[01]/[0-9]{1,2} ?(PM |사용자 )?결정' docs/brd.md docs/prd.md
grep -c '^| 날짜 | 버전' docs/brd.md docs/prd.md
grep -c '전체 300ms' docs/prd.md
python -m unittest tests.tools.test_team_plan_hours
python -m tools.check_docs --diff origin/dev
python -m tools.check_secrets
```
## 출력
```
결정 번호(P-xx): BRD 33 → 0, PRD 55 → 0
결정 날짜 표현·변경 기록 표: 두 문서 모두 0
광고 "전체 300ms": 0 (800ms로 적음)

```
