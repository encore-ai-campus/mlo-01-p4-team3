# C-09-02 개인정보 재유입 차단과 보존 준비

- 커밋: 7b7ae4b 기반
- 작성자(흐름): C
- 환경: 실제 Spark VM의 격리 Delta, 실제 Kafka 보존 설정 조회
- 상태: 부분 완료. 저장소별 실제 삭제와 보존 예약·실행 검증은 미완료.

격리 Delta에 두 원본을 쓴 뒤 하나를 삭제하고 제외 목록을 적용해 같은 입력을 재처리했다. 삭제 대상은 0건, 비대상은 1건을 유지했다. 감사에는 재처리 2건의 offset 0–1, 삽입 0건, 기존 중복 1건, 제외 1건이 남았다. 게임 가명과 광고 세션 가명·재판정 키는 계약 시험에서 분리 검증했다.

Kafka 10개 토픽의 `retention.ms=86400000`, `segment.ms=604800000`와 broker 점검 주기 `300000`을 읽었다. 설정 합계 추정은 8일 5분이다. 원문과 설문 저장 경로의 `mask_version=b-mask-1` 기록을 코드에서 확인했다.

## 명령

```sh
python -m unittest tests.contract.test_privacy_replay tests.contract.test_pipeline_bronze -v
python -m tools.privacy_delete --help
```
