# C-05-01 VM 20대 실측과 점검표 양식
- 커밋: b3c654b
- 작성자(흐름): E
- 환경: 노트북 3(Windows 11, VMware Workstation), Git Bash, WSL2 Ubuntu(스크립트 시험용)
- 상태: 진행 중. 담당 C가 11/5 밤 연락이 닿지 않아 PM이 노트북 3에서 가능한 부분(양식, 점검 스크립트 2개, 노트북 3 호스트 실측)을 대신 했다. 태스크 담당은 C 그대로다.
## 명령
```
powershell -ExecutionPolicy Bypass -File ops\inventory_host.ps1
"C:\Program Files\VMware\VMware Workstation\vmrun.exe" list
bash -n tools/perf/vm_probe.sh
wsl.exe -e bash -s probe-test < tools/perf/vm_probe.sh        # 스크립트 시험(실제 VM이 아니라 WSL)
# SSH 도달 확인: 20대 각각 키 인증 비대화형(BatchMode), 접속 시간 제한 6초
ssh -o BatchMode=yes -o ConnectTimeout=6 <접속 별칭> 'echo ok'
```
