# C-07-02 실제 브로커·발행기 정지/재개 무손실
- 커밋: 0800b502b0bd8af7e41d0e22882ef25eb03aa3ee
- 작성자(흐름): C
- 환경: 실제 Kafka 3브로커, Mongo RS, MySQL 계정 세션, Daphne/Caddy HTTPS, 공식 Spark/Delta. 실측일 2026-11-08.

인증정보를 다른 호스트로 복사하지 않았다. 같은 웹 VM의 **전용 loopback HTTPS 검증 프로세스**가 실제 운영 조립·DB·엔진을 사용한다. 검증 판은 load_test=true이고 실사용자 판은 없다. 각 판 next_seq=52, Kafka 고유=52, bronze=52. API는 두 판 각 7회 모두 성공했다. 검증용 프로세스는 종료했고 운영 웹은 정상 factory로 복구했다. 공개 웹 브라우저 흐름은 C-07-04에서 별도 검증했다.

## 명령

```sh
# 웹 호스트에서 prepare로 새 합성 참가자·세션 생성, --serve로 loopback 검증 프로세스 실행
python -m server.tests.live_stack --profile "$PRIVATE_RUNTIME" --out "$PRIVATE_ACTORS"
# 실제 브로커 1대 또는 Outbox 발행기만 정지. 90초 자동 재개 안전 타이머 병행
# 같은 호스트의 보호 쿠키로 실제 HTTPS 게임을 진행·완료하고 정지한 서비스 재개
spark-submit <외부 JAR·TLS 옵션> pipeline/spark/export_faults.py --config "$PRIVATE_CONFIG" --mongo "$PRIVATE_MONGO_METADATA" --out "$PRIVATE_BRONZE_METADATA"
python -m tools.reconcile_game_events --mongo "$PRIVATE_MONGO_METADATA" --published "$PRIVATE_KAFKA_METADATA" --bronze "$PRIVATE_BRONZE_METADATA" --out "$PRIVATE_RESULT"
python -m unittest tests.contract.test_reconcile_events -v
```

실행 주소·보호 파일 경로는 저장소 밖 인계 기록에 있다. 아래 명령의 `$PRIVATE_*`는 그 경로이며 자격정보를 CLI로 전달하지 않는다.
