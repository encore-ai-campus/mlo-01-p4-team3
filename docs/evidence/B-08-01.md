### 최신 dev ed30866 반영·재검증(11/9)

일반 판과 고정 회차 모두에 결말 선택을 연결했다. 일반 판의 폼·JSON은 시작 UUID·남성 초상·한풀이 선택을 함께 저장하며 같은 UUID의 재전송은 공개 프리셋 설정이 바뀌거나 다른 결말·초상을 보내도 최초 판을 반환한다. 잠긴 한풀이는 두 입력 형식에서 400이며 판을 생성하지 않는다. 고정 회차의 최초 선택 유지·B-08-02의 초상·심문·거절 코드·Kanana 표기 제거와 기존 저장 응답 복구는 보존했다.

```text
Ran 34 tests in 3.991s
OK
Ran 202 tests in 55.703s
OK
isolated_mysql_exit=0
```

관련 34건은 `test_story_ui`(8건)·`test_open_start`·`test_preset_screens`다. 전체 서버 202건은 Django 6.1.2·격리 MySQL 8.4.11에서 건너뜀 없이 통과했고 실제 Mongo 운영 팩토리 회귀도 포함했다. 게임/진척 화면 시험은 메모리 저장소·녹화 엔진을 사용한다. 실제 고백→단서 획득·해금의 통합 완료를 뜻하지 않는다. MySQL 종료·임시 데이터 정리를 확인했다. 원자료: `out/handoff/b0801-final-targeted.log`, `b0801-latest-mysql.log`, `b0801-latest-mysql-run.log`.

Browser plugin not available. 기존 Playwright·Chrome으로 고정 판 퇴마 종료 → 수집 단서 3개 확인 → 홈 일반 판에서 한풀이·남성 초상 선택 → 다음 판 한풀이 종료를 다시 확인했다. 제목·URL·본문·정상 화면·실제 조작과 1280×900·390×844 캡처를 검사했다. 콘솔/페이지 오류·리소스 실패·가로 넘침은 0건이다. 단서·해금은 검수용 대역이며 운영에 연결하지 않았다. 녹화 판은 자유로운 규칙 판단 시험과 구분한다. 원자료: `out/handoff/b0801-latest-browser.log`, 임시 조립 `preview_story.py`·`story-browser.cjs`. 화면은 저장소 밖 백업의 `B-08-01-result-desktop.png`, `B-08-01-progress-mobile.png`, `B-08-01-haewon-mobile.png`에 보관했다.
