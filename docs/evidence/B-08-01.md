### 판 종료 화면 안 결과·복기·원한 단서, 선택형 도전(11/9)

- 판이 끝나면 같은 `#meeting` 안에 결과·복기·원한 단서 탭을 둔다. 결과 탭은 승패·종료 사유·결말 문안·`result_banner`·설문, 복기 탭은 B-10-01(정체·숨긴 비밀·이 판 단서·`review_side`), 단서 탭은 모든 판에서 모은 단서와 결말 해금 상태다. 복기·단서는 탭을 열 때 htmx 조각으로 불러와 페이지를 옮기지 않는다(사용자 결정: 판 밖 이동 없이 게임 화면 안).
- 홈 판 구성 목록은 `presets_enabled.json`에 공개된 도전만 `선택형 도전` 묶음(이름·인원)으로 보인다. 지금 설정은 base6뿐이라(E-09-08 공개 조건 미충족) 화면에는 없다. 공개된 프리셋 ID로 판을 시작하는 경로는 B-08-02의 같은 공개 프리셋 시험이 확인한다.
- 진척 문서에 `exorcism`이 없으면 퇴마까지 잠겨 보이던 오류를 엔진 `ending_available`로 고쳤다.
- 관련 서버 시험 71건 통과(36.051초): `test_game_end`(7건 신규)·`test_story_ui`·`test_review`·`test_meeting`·`test_sessions`·`test_preset_screens`·`test_open_start`·`test_ad_slots`·`test_survey_skip`.
- 브라우저: 저장소 밖 임시 LiveServerTestCase와 headless Chrome(CDP)으로 녹화 판을 끝낸 뒤 1280·360 폭에서 탭을 눌러 확인했다. 두 폭 모두 결과 표시·복기 로드·단서 로드·복기 지면 1개·같은 URL·주 문서 이동 1회(처음 열기)·가로 넘침 0 이하·페이지 오류 0. WSGI 시험 서버라 웹소켓 404가 폭마다 3건 있었고 이번 변경과 무관하다. 결과: [`perf/B-08-01/browser_end_screen.json`](perf/B-08-01/browser_end_screen.json). 화면은 저장소 밖 `b0801_screens/end_{result,review,clues}_{1280,360}.png`에 보관했다.
- 처음에는 복기·단서 패널에 `hx-trigger="intersect once"`를 썼는데 JS로 `hidden`을 푼 패널에서 요청이 나가지 않았다(Chrome 측정 review_loaded false). 탭 스크립트가 `paldo:end-open` 사건을 보내도록 바꾼 뒤 통과했다.
- 첫 요청이 실패하면 탭이 "불러오는 중"에 멈춰 새로 고침 전에는 다시 읽을 수 없었다(Codex 지적). 성공한 패널만 다시 읽지 않고, 실패하면 "불러오지 못했습니다. 탭을 다시 누르면 다시 시도합니다."를 보인 뒤 탭을 다시 누를 때 다시 요청하게 고쳤다. Chrome 360에서 복기 요청을 막아 안내 표시 → 풀고 다시 눌러 로드 → 다시 열어도 지면 1개를 확인했다(같은 JSON의 `retry_after_failure_360`).
