# E-08-02 추가 콘텐츠 (주민 2명, 7·8인 판)
- 커밋: edae77caaa794eb2009bd6d66e5d1d8eb432b0c6
- 작성자(흐름): E
- 상태: 통과. 자동 검사(조건의 수치)를 모두 통과했고, 새 인물 설정·말투·외형·비밀 고백 대사는 11/7 사용자 확인을 받았다(README 7절 "스토리·대사 산출물 검토", 스님 말투에 자칭 '소승' 추가 요청 반영).
- 병합 시점(11/7 사용자 결정): 엔진이 판마다 주민 풀 전체에서 뽑아 6인 판에도 두 인물이 나올 수 있으므로, 11/9 정식 사용자 테스트가 끝난 뒤 병합한다(두 인물의 실제 그림은 A-11-04, 11/11).
- 환경: 로컬 Windows 11, Python 3.14(miniconda, 표준 라이브러리 + `engine` 패키지), 작업 트리 `paldo-E-08-02`(브랜치 `task/E-08-02`, `origin/dev` edae77c에서 땀). 위 커밋은 작업을 시작한 기준 커밋이고, 바뀐 파일은 이 PR의 커밋에 있다. 같은 PC에서 다른 작업(의도 변형 생성, 결정 층 최적화 등)이 함께 돌아 테스트 시간은 대표값이 아니다.
- 추가 주민(11/7 사용자 결정): 사냥꾼 `hunter`(다혈질 `hothead`, 키 등급 `tall`), 떠돌이 스님 `monk`(겁쟁이 `timid`, 키 등급 `male`). ID는 기존 임시 에셋 ID 그대로다(`content/images/manifest.json`, A-11-04 sprite 입력). 표정 변형 대상이 아니다(추가 주민은 기본 그림 1장, 11/5 PM 결정, `docs/assets/spec.md` 9절).
- 외형 설명 위치: `ContentBundle`에 외형 필드가 없어 기존 관례대로 `content/README.md` "인물 외형 메모" 표에 두 행을 더했다(A-11-04 입력).
- 비밀: 기존 비밀 수 6개로도 `large8`의 `n_secret` 3을 넘지만, 새 인물이 비밀을 가질 수 있게 자격을 넓혔다. 사냥꾼은 `gambling`·`tryst`·`drinking`, 스님은 `letter`에 더했다(고백 대사가 그 인물이 말해도 맞는 비밀만). 스님이 가질 비밀이 하나뿐이라 새 비밀 `rite`(몰래 올린 제, 저녁·서낭당, 원한 단서 없음)를 더했다. 같은 시간대·실제 장소의 다른 비밀이 없어 충돌 제약은 없다.
- 말투 계열: 추궁 표현 프롬프트(`llm/prompt.py` `STYLE_PROFILES`)는 말투 설명의 낱말로 계열을 고른다. 사냥꾼은 `하게체`, 스님은 미리 있던 `합장` 계열로 잡히게 말투 설명을 썼다(`tests/llm/test_mvp_metrics.py`에 두 인물 기대값 추가).
- 원본과 다른 점: 결과 JSON을 이 태스크 폴더에 쓰도록 `tools/check_content.py`에 `--task` 인자를 더했다(기본값은 원래대로 E-05-03). 템플릿은 성향별로 이미 있어 새로 쓰지 않았다(47개 그대로).
- 주의: 엔진(`make_setup`)은 판마다 주민 풀 전체에서 인원만큼 뽑는다. 이 변경이 들어가면 6인 판에도 사냥꾼·스님이 나올 수 있고, 두 인물의 실제 그림은 A-11-04(11/11) 전까지 임시 그림이다.
