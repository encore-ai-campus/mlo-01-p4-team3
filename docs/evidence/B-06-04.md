# B-06-04 계정 가입·로그인

- 커밋: 57f98a7b3aa6109e6e5e1c8fbf99249e14456ef0
- 작성자(흐름): B
- 환경: Windows, Python 3.14.6, Django 6.1.2, 격리 MySQL 8.4.11. 게임 검증에는 녹화 엔진과 메모리 저장소를 사용했다.
- 상태: 실패

조건 5 중 실제 광고 요청의 식별자 검사가 남았다. 가입 횟수 제한 삭제는 최신 계약대로 반영했다.

## 명령

```powershell
python -B out/handoff/check_accounts_session_contract.py
python -B server/manage.py test server.tests --settings=server.paldo_web.mysql_test_settings --noinput --verbosity=2
python -B server/manage.py makemigrations --check --dry-run --settings=server.paldo_web.test_settings
python -B -m tools.check_evidence B-06-04 --format
```

격리 MySQL의 시험 스키마와 운영 설정용 스키마를 분리했다. 운영 설정용 스키마에 이전 계정 스키마와 계정 프로필·잠금·세션·가입 카운터를 만든 뒤 최신 마이그레이션을 적용했다. 원본 출력은 `out/handoff/mysql-8411-session-contract-*.log`에 있다. 검증 기준은 최신 dev cda5591이다.
