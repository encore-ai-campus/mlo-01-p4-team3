# C-07-04 HTTPS·실제 인증서 경고·wss·프록시 지연
- 커밋: 000ef0b62c93e5cca3f2fe8227b5e8615673ba95
- 작성자(흐름): C
- 환경: Caddy 2.6.2-14, Daphne 단일 프로세스, Chrome 157.0.8103.38, Linux VM 두 물리 호스트. 실측일 2026-11-08.

초기 자동 검증은 새 테스트 컨텍스트의 인증서 예외로 가입·로그인·판 시작을 검증했다. 추가 검증은 **다른 물리 노트북**의 새 Chrome 컨텍스트에서 TLS 검증을 켠 채 실제 경고 UI의 Advanced/Proceed를 눌러 기존 판을 열고 wss 101을 확인했다. OS 인증서 저장소는 바꾸지 않았다. Edge 직접 실측과 실제 참가자 네트워크 접속 확인은 운영 안내 시 각 기기에서 수행한다. 테스트 계정·쿠키는 생성한 호스트 밖으로 내보내지 않았다.

## 명령

```sh
caddy validate --config "$PRIVATE_CADDYFILE"
python ops/proxy/header_probe.py --template ops/proxy/Caddyfile
python ops/proxy/browser_check.py --origin "$PRIVATE_ORIGIN" --directory "$PRIVATE_BROWSER_DIR" --phase register
python ops/proxy/browser_check.py --origin "$PRIVATE_ORIGIN" --directory "$PRIVATE_BROWSER_DIR" --phase game
python ops/proxy/browser_check.py --origin "$PRIVATE_ORIGIN" --directory "$PRIVATE_BROWSER_DIR" --phase game --certificate-interstitial
python -m tools.perf.api_bench --proxy-profile "$PRIVATE_ACTORS" --seconds 60 --out "$PRIVATE_BENCH_RESULT"
```

실행 주소·보호 파일 경로는 저장소 밖 인계 기록에 있다. 아래 명령의 `$PRIVATE_*`는 그 경로이며 자격정보를 CLI로 전달하지 않는다.

## 출력

```json
{"game_started": true, "wss_101": true, "websocket_statuses": [101, 101], "session_secure": true, "csrf_secure": true, "mixed_content": 0, "external_ad_requests": 0, "page_errors": 0, "browser": "157.0.8103.38", "certificate_exception": "browser_warning_ui", "warning_bypassed": true, "ignore_https_errors": false}
```
