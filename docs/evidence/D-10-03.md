## 출력

현재 승률 모델은 1,600판·2,703행으로 학습하고 별도 400판·672개 판-일로 평가했다. 날짜·프리셋·감금·고백·실종 건수를 각 날짜의 최초 공개 관측에서 읽었다. 진실은 승패 라벨에만 사용했다. 모델 로그 손실 0.614182, 상수 기준선 0.671384, 모델 ECE 0.043722, 기준선 ECE 0.040390다. 예측 평균 0.427274와 실제 승리 비율 0.388393는 같은 평가 판-일을 사용했다. ECE 구간은 10개다.

`model.json`의 유한 계수·특징 버전·규칙·콘텐츠·프리셋을 검증하고 웹에서 표준 라이브러리로 추론한다. 설정 `PALDO_WIN_PROBABILITY_MODEL`을 지정하면 종료된 자기 판의 실제 아웃박스 관측으로 `review_trace.win_prob`와 `ReviewOutput.win_prob`를 채운다. 형식은 `[{"day": 1, "probability": 0.65}]`다. 설정 없음·로드 오류·버전 불일치·중단 판은 null이다. 현재 공개 상태에서 과거 확률을 다시 만들지 않는다.

평가 400판의 672개 확률을 복기 형식으로 재생했다. sklearn 내보내기 대비 최대 오차는 1.11e-16이었다. 복기 API 소유권·종료 경계, DTO, D3 화면 숨김과 E-10-01 해설을 검사했다. 로컬 Django `/metrics`의 두 지표 값이 평가 보고서와 일치했다. Grafana 패널 설정이 그 지표를 조회하는 것도 검사했다. `scope=offline_holdout`는 봇 평가의 고정 표본이다. D3 표시 결정과 운영 모델 설정·Grafana 배포 검증은 대기다.

자기 대전은 마을·씐 자 NPC가 각각 자기 관측의 안전한 후보 중 최고·두 번째·최저 순위 선택을 학습하는 표 기반 정책이다. 상태는 자기 진영·날짜·일반/결선·신뢰도 구간·후보 수 구간이며 최대 날짜 구간은 3일째 이상을 함께 묶는다. ε=0.2로 1,000판 학습하고 첫 방문 Monte Carlo 평균을 진영별 종료 보상으로 갱신했다. 평가 때는 표를 고정한다. 안전 후보가 모두 빠지면 기존 최대 의심도 폴백을 쓴다. NPC 모델 호출은 기존 추정 포트와 같은 경계다. 플레이어는 LogicBot, 추정은 양쪽 모두 FakeSuspicionModel로 고정한 개발 비교다.

| 정책 | 평가 시드 | 판 수 | 마을 승률 (Wilson 95%) | 일수 | 합법 위반 |
|---|---|---:|---|---|---:|
| A rule-v0 | 1111001000–1111001999 | 1,000 | 49.7% (46.6%–52.8%) | 1–3 | 0 |
| selfplay-tabular-v1 | 같은 시드 | 1,000 | 85.3% (83.0%–87.4%) | 1–3 | 0 |

학습 시드는 1111000000–1111000999로 평가와 겹치지 않는다. 양 진영이 학습했고 상태는 26개다. 학습 정책의 마을 승률 85.3%는 균형 목표 40~60%를 벗어나 채택하지 않았다. 정책 표·각 판 시드·결과·궤적 SHA-256은 `out/d1003/selfplay-098b077`에 있다. 이 비교는 A-10-01의 보정 알리바이 봇·실제 모델 v0 운영 관문과 별개다.
