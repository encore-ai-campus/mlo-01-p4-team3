# C-09-01 MLflow 평가 관문

- 커밋: 7b7ae4b 기반
- 작성자(흐름): C
- 환경: 실제 NiFi VM, MLflow 3.18.0, Garage TLS
- 상태: 부분 완료. D 평가 함수와 웹 ModelSelector 연결 검증은 미완료.

NiFi VM에서 추적·레지스트리를 기동하고 전용 Garage 버킷을 연결했다. 가짜 아티팩트의 업로드·다운로드, 필수 메타데이터 없는 실행과 평가 실패의 거절 태그, 가짜 통과 실행의 candidate 별칭 조회를 확인했다.

## 명령

```sh
python -m unittest tests.ops.test_ml_gate -v
python -m tools.ml_gate --run-id "$RUN_ID" --model suspicion --artifact model --evaluator module:function
```

## 출력

가짜 모델 1개 candidate 조회 성공. 메타데이터 누락 1회, 평가 실패 1회 거절.

## 수치

| 조건 | 기준 | 측정값 | 측정 방법(지표 이름 또는 스크립트) | 결과 파일 | 통과 |
|---|---|---|---|---|---|
| 1 | Garage 업·다운로드와 별칭 조회 | 각 1회 | 실제 MLflow 가짜 모델 시험 | - | 예 |
| 2 | 메타데이터 누락 거절 | 1회 | 실제 실행 태그 조회 | - | 예 |
| 3 | 평가 실패 거절 | 1회 | 실제 실행 태그 및 등록 여부 조회 | - | 예 |
