## 로그

RunPod는 사용자 의견으로 추가한 후보이며 확정으로 해석하지 않았다. 일반 OpenAI 호환 endpoint를 PALDO_LLM_URL로 바로 연결하면 E의 renders/poll/cancel 계약과 맞지 않는다는 인계 사항을 적었다. GPU 종류·가격·VRAM 수치를 추정해 완료 값으로 기입하지 않았다. 새 유료 자원 생성·결제·서버 정지는 실행하지 않았다.

Garage는 실제 사용 중인 두 노드가 쓰기에 필요하므로 초기 media-storage-01 끄기 계획을 수정했다. 기존 데이터 삭제를 전제로 한 문구도 실제 보존·추가 생성 방식으로 정정했다.
