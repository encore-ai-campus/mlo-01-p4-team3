# B-05-03 회의 화면 (htmx)

- 커밋: 592d734f5ec5aa6aba2c647c3da62c1064f2fe33
- 작성자(흐름): B
- 환경: Windows, Python 3.14.6, Django 6.1.2, 시험용 SQLite·녹화 엔진·메모리 게임 저장소. 브라우저 확인은 로컬 Chrome 156.0.8078.48, Playwright로 실행했다.

## 명령

```powershell
python -B server/manage.py test server.tests --settings=server.paldo_web.test_settings --noinput --verbosity=2
python -B server/preview.py --port 8769
python -B -m tools.check_evidence B-05-03 --complete
python -B -m tools.check_structure --diff origin/dev
python -B -m tools.check_docs --diff origin/dev
```

미리보기 로그인 후 녹화 명령과 같은 순서로 폼을 제출했다. 데스크톱 1366×768에서 명령 12회와 오래된 탭의 409를, 모바일 크기 390×844에서 첫 갱신과 이미지 표시를 확인했다.

## 출력

```text
Manifest images verified: 102 (8 ads)
Ran 48 tests in 4.224s
OK
```

별도로 공통 계약·에셋 규격 시험 66개가 통과했다. 최신 대장장이·사냥꾼의 기본 초상·스프라이트 4개 파일을 직접 열어 형식과 스프라이트 기준선을 확인했다.

렌더 시간은 계정·판 준비를 제외한 전체 화면 GET 100회의 서버 응답 시간이다. 재검증에서 오름차순 95번째 값인 p95는 8.400 ms였다. 브라우저의 화면 그리기와 이미지 다운로드 시간은 이 측정 범위 밖이다.

루트 README의 B 영역 행에 템플릿·정적 파일 위치를 명시한 뒤 구조·문서 변경 검사를 통과했다.
