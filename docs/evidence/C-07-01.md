# C-07-01 공식 bronze·silver·라벨·200판 실스택 검증
- 커밋: 28077a1f8cab5bd2446eff45b5600ca699690cbe
- 작성자(흐름): C
- 환경: Spark 4.1.3, Delta 4.4.1(Spark 4.1용), Hadoop 3.4.2, Java 21, Garage. 실측일 2026-11-08.

200판 입력 파일 SHA-256: `223693b71da23135fcc2750ea1b1e20637e99c05d2f63e4ef106e3d458fdf23a`. 재전송 대조 시 전체 bronze에는 선행 검증 20건도 있어 17,843건이었고, 200판만 조회하면 원본과 같은 17,823건이다. 이후 장애·브라우저·광고 검증 행이 추가된다. silver 19,191행, 학습 JSON export 14,460행. D 학습 완료를 뜻하지 않는다.

## 명령

```sh
python -m tools.run_engine_games --preset base6 --games 200 --seed 1 --out out/handoff/c07-200
python -m pipeline.consumers.publish_jsonl --help
# 같은 events.jsonl을 보호 Kafka 설정으로 처음과 재전송 때 각각 발행
spark-submit <외부 JAR·TLS 옵션> pipeline/spark/ingest_bronze.py --config "$PRIVATE_CONFIG" --available-now
spark-submit <외부 JAR·TLS 옵션> pipeline/spark/build_silver.py --config "$PRIVATE_CONFIG"
spark-submit <외부 JAR·TLS 옵션> pipeline/spark/join_labels.py --config "$PRIVATE_CONFIG"
spark-submit <외부 JAR·TLS 옵션> pipeline/spark/verify_run.py --config "$PRIVATE_CONFIG" --events "$PRIVATE_EVENTS" --name after-replay
python -m unittest tests.contract.test_pipeline_bronze tests.contract.test_pipeline_silver -v
```

실행 주소·보호 파일 경로는 저장소 밖 인계 기록에 있다. 아래 명령의 `$PRIVATE_*`는 그 경로이며 자격정보를 CLI로 전달하지 않는다.
