# D-11-01 재학습·시나리오 최종 재실행

- 상태: 완료 조건 충족
- 커밋: f87948f829be78af0b16575341edc6314fde3c2c
- 작성자(흐름): D
- 환경: 독립 worktree `2fa3`, Windows Python 3.14.6 CPU, 격리 MLflow 3.18.0 SQLite, 로컬 Spark 4.1.3·Delta 4.4.1.

`dev`의 C-08-02 완료(PR #427)를 확인하고 광고 1~5의 관측과 확정 원장을 같은 실행에서 저장하도록 보완했다. 최종 계측 커밋은 광고 소재 경로 변경(PR #430)까지 반영한 `f87948f`다. 이전 부분 PR #421의 실측 JSON은 보존했다.

## 명령

공식 입력은 E가 검수한 보호 사본을 읽고 C의 현재 삭제 목록을 대조했다. 재학습 출력은 현재 사용자만 접근할 수 있는 Git 제외 경로를 사용했다. 아래 `PALDO_D1101_*` 변수는 그 실행의 비공개 입력·출력 경로다.

```powershell
python -X utf8 out/d1101/verify_latest_tombstones.py
python -X utf8 out/d1101/verify_official.py
python -X utf8 -m intent.retrain --freeze "$env:PALDO_D1101_FREEZE" --train-labels "$env:PALDO_D1101_TRAIN_LABELS" --eval-labels "$env:PALDO_D1101_EVAL_LABELS" --contexts "$env:PALDO_D1101_CONTEXTS" --tombstones "$env:PALDO_D1101_TOMBSTONES" --cache "$env:PALDO_D1101_CACHE" --data-version 'freeze:5b217f61151407797b050c5a80e88f51615314d123c8a1012916c991229d6f1a' --first-model --out "$env:PALDO_D1101_INTENT_OUT" --registry-dir "$env:PALDO_D1101_REGISTRY_OUT" --threads 4
python -X utf8 out/d1101/run_final_thompson.py out/d1101/final_f87948f
python -X utf8 -m tools.ad_ctr_scenario prepare --out out/d1101/final_f87948f/scenario6 --requests 12000
python -X utf8 out/d1101/scenario6_delta_f87948f.py out/d1101/final_f87948f/scenario6 "$env:PALDO_D1101_DELTA_JARS"
python -X utf8 out/d1101/reconcile_f87948f.py out/d1101/final_f87948f "$env:PALDO_D1101_DELTA_JARS"
python -X utf8 out/d1101/record_intent_and_scenario6_f87948f.py
python -X utf8 out/d1101/record_final_scenarios.py out/d1101/final_f87948f
python -X utf8 -m tools.check_evidence D-11-01 --complete
```

`run_final_thompson.py`는 `tools.ad_scenarios.run_policy`에 각 시나리오와 시드 17·29·43, 12,000요청, `replay_out`을 전달한다. 기존 CLI에서도 `--capture-replay`로 톰슨 관측을 내보낼 수 있다. 관측 JSONL에는 온라인 serve·비콘·클릭의 판정과 금액이 들어가며, 별도 원장은 온라인 `BudgetBook`을 그대로 내보낸다. 확률 정답은 대사에 전달하지 않는다.

Spark 실행기는 Windows에서 루프백 `local[2]` 단일 writer 세션을 사용한다. 시나리오별 세 시드의 JSONL을 새 Bronze Delta로 적재하고, `pipeline.spark.ads_silver`가 재판정한 Silver Delta를 `pipeline.spark.ads_reconcile`이 온라인 확정 원장과 건별로 대조한다. 시나리오 6은 `pipeline.spark.ads_gold`의 확정 마감·대사·학습 행 export를 사용한다. 로컬 보조 실행기와 원본 로그는 `out/d1101/`에 있다.

## 출력

- **공식 의도 재학습 ⓪**. D-09-01 공식 평가가 BERT와 TF-IDF 각각 6/7로 동률이어서 기준선 유지로 판정했다. E의 공식 동결과 라벨·당시 공개 맥락 해시, 정식 참가자의 동의, Bronze 버전 245를 확인했다. C-09-02 현재 목록을 11/11 21:02:22 KST에 읽어 보호 사본과 네 종류 모두 0건으로 일치함을 확인했다. 공식 학습 9건·평가 7건으로 실행했고 삭제 가명과 자동 실행 라벨은 학습에 0건 남았다.
- **관문**. 후보 0/7, 기준선 6/7로 거부했다. 사유는 `command_exact_match`, `macro_f1`, `invalid_or_missing_measurement`다. 평가에 미지원·대조쌍 사례가 없었다. 격리 MLflow run `01ae7770ad4f40868078c675fce6f769`에서 `paldo.gate.status=rejected`, 데이터·특징·코드 버전과 등록 버전 0개를 조회했다. 소요 시간은 130.401초다.
- **광고 1~5**. `97d2e2d`에서는 네 정책 전체 60회·720,000요청을 실행했다. 최종 커밋에서는 판정 대상 톰슨 15회·180,000요청을 다시 실행했다. 합격 판정 지표가 일치했고, 관측 JSONL·원장·cutoff의 SHA-256도 시나리오·시드별로 일치했다. 온라인 예측의 시나리오 2 최대오차 22.077%는 진단 지표로 보존했다. 기존 합격 판정은 최종 posterior 오차를 사용한다.
- **광고 6**. 최종 커밋에서 새로 생성한 합성 154,000건을 별도 Delta에 적재했다. 확정 학습 576행의 출처는 `delta:ads-ctr:84648ee61058f879:0`다. 평가 노출 35,898건에서 LightGBM 최대 CTR 상대오차 3.159%, ECE 0.002809, 로그 손실 베타 0.416478 → LightGBM 0.389471였다. 승리 CTR이 세 평가 시드 모두 패배 CTR보다 높았다. 무효 과금과 확정 원장 대사 불일치는 각각 0건이다.
