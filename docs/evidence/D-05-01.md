### 평가 조건과 해석 범위
- 시드 50문장을 원본 계보와 대조쌍이 같은 쪽에 남도록 분할했다. 시드 7로 학습 35문장·평가 15문장, 양쪽 모두 라벨 10종이다. TF-IDF와 로지스틱 회귀는 학습 분할에만 fit했다. 별칭·파생 문장이 원본 계보를 넘어가지 않는 테스트도 통과했다.
- 명령 전체 일치율은 라벨뿐 아니라 `Command` 전체 필드를 비교한다. 근거 목록의 순서만 무시한다. 평가 공개 문맥은 `intent/evaluation.py::reference_case`에 고정했다: P1=훈장, P2=주모, 선택 인물=훈장, 직전 상대=주모, 공개된 밤=0, 선택 근거=공개 주장 2개. 정답에서 생략된 슬롯은 누락 상태도 비교하며, 점괘의 최근 공개 밤 기본값과 문장에 명시된 어젯밤 해소를 반영한다.
- 미지원 검출률 1.0은 평가 분할의 미지원 문장 **1개 중 1개**를 검출한 값이다. 일반적인 미지원 문장 전체에 대한 성능을 의미하지 않는다. 매크로 F1 0.25·명령 전체 일치율 0.266667도 작은 시드 기준선의 실측값 그대로 보고한다.
- 지연은 모델 로딩·학습을 제외하고 준비 실행 후 `parse`의 분류부터 슬롯 검증까지 1,000회 측정했다. 측정 당시 프로젝트 VM 4대가 실행 중이었다.
- 데이터 SHA-256은 `a669565c6e2f0f1c54dc04d6fcca5e88a6205136c6c2f466249087a036ecb261`, 특징 버전은 `char-2-5-nfc-v1`이다. 학습/평가 ID·개별 예측·패키지 버전·코드 커밋은 로컬 `mlruns/intent-v0/tfidf-lr-v0-22eff210cb7d/run.json`, 모델은 같은 폴더의 `model.joblib`에 기록했다. `mlruns/`는 Git에서 제외한다.
- 공유 포트·엔진 스키마는 바꾸지 않았다. 의심 이유 질문의 `mentioned`는 기존 `Command.target`, 수신자는 `Command.addressee`로 구분한다. `needs_confirmation`은 항상 true이며 명령 실행이나 행동 소비는 하지 않는다.
