### 얼굴 편집·합성 시험

기존 `Downloads/task/A-09-05/sprite/mudang_f.png`를 **편집 기능 시험용 입력**으로 사용했다.
이 보정본에는 이전 세로 구간별 정렬이 포함되어 있어 최신 키 등급·비율 규격의 최종 에셋으로 승인한 것이 아니다.
입력 얼굴 크롭과 기본 sprite를 참고로 다음 편집 요청을 실행했다.

```text
Precise facial-expression edit. Image 1 is the EXACT EDIT TARGET: a 192x208 px face crop from a Korean female shaman sprite. Image 2 is full-body CONTEXT ONLY. Return ONLY the same face crop viewport as image 1, NOT the full body. Change only the expression to a gentle, restrained happy smile: subtly raised mouth corners, softly relaxed brows, both eyes still open. Preserve the exact character identity, adult age, head/face shape, skin color, eye size and positions, hairstyle, hat, beads, lighting, linework and framing. No blush, tears, sweat, sparkles, text, or new accessories. All clothing and hair/hat/beads must remain unchanged. Keep the entire same crop contents and edges, without zoom, pan or rotation. Output transparent PNG with preserved alpha, same aspect ratio 192:208 (12:13), ideally exactly 192x208 pixels. The result will be composited into only the face rectangle of the original sprite, so its crop placement must match image 1.
```

도구는 얼굴 표정을 바꾼 이미지를 반환했다. 입력 크롭은 이전 좌표의 192×208이었고, 편집 출력은 1205×1305여서 그대로 덮어쓰지 않았다.
편집 결과를 가로·세로 **같은 배율**로 축소하고, 최신 `vn.face_box("mudang_f")`인 `(162, 169, 350, 371)`(끝 미포함) 안에서 얼굴 안쪽만 기본 그림에 합성했다. 영역 밖은 기본 픽셀을 그대로 보존했다.
기존 편집 결과를 새 허용 영역에 맞춰 재합성·재검사한 것이며 추가 생성 횟수와 얼굴 편집 횟수를 섞지 않는다.
