# C-08-04 콘텐츠 대조·사용자 테스트 준비
- 커밋: 43d21ad4ad7081f4856832313e654556dc72545a
- 작성자(흐름): C
- 환경: 2026-11-08 실제 PJ4 VM, Python 3.14.4.
- 상태: 부분 완료. 아래 미완료 조건을 유지하고 Refs PR로 제출한다.

운영 paldo_web의 content-1.0과 후보 5315516의 bundle을 같은 DTO로 읽고 정규 직렬화 SHA를 대조해 일치했다. 두 SHA는 로그와 같다. 내용이 같아 재적재하지 않았다. E가 최종 태그를 확정하면 그 SHA에서 다시 비교해야 한다.

**미완료 조건 2:** 원격 v-usertest-1/2 태그가 아직 없다. E 소유 태그를 임의로 만들지 않았으며 main/dev 최신으로 사용자 테스트 배포 완료를 주장하지 않는다. `release` 도구는 기존 태그의 SHA만 archive하고 manifest에 고정한다.

**미완료 조건 3:** 4th_private 실제 전달 위치를 로컬·접근 가능한 GitHub 저장소·연결 Drive에서 찾지 못했다. 경로를 확인하기 전에는 계정을 만들지 않았고 자격정보를 다른 곳에 기록하지 않았다. reader 도구의 경로 우회/덮어쓰기 guard와 dev/main 거절은 단위 시험했다. 운영 read·쓰기 거절 code13은 **아직 실행하지 않았다**.

**미완료 조건 4:** PM #267의 D 접속 전달을 추가 반영했다. 광고 DB·TLS·Garage 공용 설정의 보호 경로와 pj4/ 쓰기 금지, D 읽기 prefix를 정리한 인계 초안은 저장소 밖에 있다. 실제 D가 접근 가능한 전달 위치와 수신 확인은 미완료다. 증빙에 계정 원문이나 보호 경로를 복사하지 않는다.

## 명령

```sh
git ls-remote --tags origin "v-usertest-*"
python ops/user_test_ops.py release --repo "$REPO" --tag "$E_TAG" --out "$PRIVATE_ARCHIVE"
# 아래 reader 명령은 보호 위치 확인 후에만 실행, 현재 미실행
python ops/user_test_ops.py reader --admin-profile "$PRIVATE_ADMIN" --ca "$PRIVATE_CA" --seed "$PRIVATE_SEED" --out "$CONFIRMED_4TH_PRIVATE/reader.json"
python -m unittest tests.ops.test_user_test_ops -v
```
