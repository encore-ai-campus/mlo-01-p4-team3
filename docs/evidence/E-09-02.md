# E-09-02 입력 검수와 사람 평가 세트 동결
- 커밋: fd02936
- 작성자(흐름): E
- 환경: 로컬 Windows 11 miniconda Python. 입력은 11/10 18:00 스냅숏을 읽기 전용으로 내보낸 파일과 사전 테스트(11/8) 내보내기다. 운영 DB에 직접 붙지 않았다
- 상태: 완료. 동결은 계획(11/10 19:30)보다 늦은 11/11 10:21에 했다(아래 트러블)

동결 실행은 원래 D 몫(D-10-01 9번)이었으나, 11/11 사용자 결정("운영에서 돌리기 위해 필요한 거면 D에 있는 것도 다른 거랑 안 겹치는 작업이면 여기서 하자")으로 E가 실행했다. 문장 원문·가명 ID가 든 파일은 저장소에 넣지 않고 NAS `5. 테스트 데이터/user_test/` 아래에 둔다.

## 명령
```
python -m server.infra.ut_export games --out games.json
python -m tools.ut_freeze --games games.json --pretest-games <사전 테스트 games.json> --pm-pseudonym <PM 가명> --seed 20261110 --exclude-set <평가 제외 집합> --privacy-review review.json --out-dir freeze_1110
sha256sum freeze_1110/manifest.json
```
마감 시각은 도구 기본값(11/10 18:00 KST, 지표 집계와 같은 시각)이다. 결과 수치는 동결 폴더의 `report.json`에서 `tools/evidence_result.py`로 `docs/evidence/perf/E-09-02/freeze_1110.json`에 옮겼다.

라벨 검수: 에이전트가 라벨·형태·슬롯 초안을 쓰고 PM(E)이 학습 절반 9행과 평가 절반 7행을 모두 확인했다(수정 없음, 11/11). 확인한 행만 `label_source=human_annotation`으로 표시했다. 학습 절반 4~6행(대상을 생략하거나 대명사로 가리킨 문장)은 입력 당시 고른 인물을 운영 보조 기록에서 읽어 `notes`만 채운 v2를 만들었다(라벨·슬롯·문장 변경 없음).

## 출력
```
freeze_version ut-freeze-1.1, normalize_version norm-1, seed 20261110, odd_rule eval=floor(n/2)
participants 7, eval_users 3, train_users 4
sentences_usertest 11, sentences_pm 5, test_human 7 (pm 5, without_pm 2)
privacy_excluded 0, privacy_excluded_train 0, sentence_conflicts 0, user_overlap 0, ok true
cutoff 2026-11-10T18:00:00+09:00, since 2026-11-10T13:00:00+09:00
manifest.json sha256 5b217f61151407797b050c5a80e88f51615314d123c8a1012916c991229d6f1a
```
