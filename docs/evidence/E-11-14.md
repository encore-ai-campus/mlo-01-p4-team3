# E-11-14 시작 화면 튜토리얼(따라 하기 판)

- 커밋: 84b26b4(작업 기준 dev, #401 투표 기권·#404 VN 모두 보기 포함. 시험은 그 위 이 태스크 작업 트리에서, 커밋 전)
- 작성자(흐름): E
- 환경: Windows, Python 3.14·Django 6.1, 메모리 SQLite, Node(화면 스크립트 시험), Chrome 1528×730(1회차 시운전은 사용자)
- 상태: 진행 중(1회차 시운전 지적 반영. 대사 사용자 확인과 2회차 Chrome 시운전 대기)

튜토리얼 판은 시드 185·base6·rule-0.9 고정, NPC 판단 모델 없음이다. 같은 명령 순서면 같은 판이 되므로 서버 시험이 14단계 전체를 실제로 끝까지 진행한다.

## 명령

```powershell
python -B server/manage.py test server.tests --settings=server.paldo_web.test_settings --noinput
python -B -m unittest discover -s tests -t .
node server/tests/test_game_js.cjs
node server/tests/test_ad_slots_js.cjs
```

## 출력

```text
server.tests: Ran 609 tests, OK (skipped=14)
unittest discover: Ran 1512 tests, OK (skipped=13)
game.js: PASS / ad_slots.js: PASS
```

- 도메인 시험(`tests/engine/test_tutorial.py`): 단계표 14단계의 날·국면, 명령 비교(대상·근거 집합·캐묻기 칸), 각본 이탈 판정 `on_script`(단계마다 날·국면이 맞을 때만 참, 끝났으면 마지막 단계 다음 버전에서 마을 승리일 때만 참).
- 서버 시험(`server/tests/test_tutorial.py`):
  - 직접 입력창 켬·끔(운영 기본 끔) 두 경로에서 14단계를 화면 HTML로 끝까지 진행해 마을 승리.
  - 단계마다 하위 단계 말풍선 문장이 대사창 줄에 미리 나오지 않는다(1회차 지적: 대사가 화면 조작보다 앞섬).
  - 하위 단계 강조 선택자의 속성·ID·값이 서버가 그린 HTML에 있다. 끔 경로 12단계는 `[의심 제기]` 펼치기·대상·제출 3개이고 입력창이 없다.
  - 판 시작 인사가 첫 아침 발표·진술 줄보다 앞, 2일째 족제비 줄이 신뢰 단서("주민들은 아직 무당님을 믿는 눈치예요.") 뒤.
  - 각본 이탈: 가짜 판단 모델(`FakeSuspicionModel`)로 실제로 흐름을 바꾸면 단계 안내가 멈추고 하위 단계는 다시 하기 하나, 로거 `paldo.tutorial`에 `tutorial_off_script` 한 번.
  - 튜토리얼 복기에서 원한 단서 묶음·광고 칸이 없고, 종료 화면에 '설득하기'·원한 단서 탭 안내가 없다.
  - 대본의 말풍선 키가 모두 실제 하위 단계 키다.
  - 튜토리얼 강제(11/11 추가): 새 계정의 JSON·HTML 일반 판 시작이 튜토리얼 판(JSON `scenario_id`), 같은 시작 UUID 재요청은 같은 판, 다음 시작은 일반 판. 진행 판이 있는 기존 계정은 새로 시작이 튜토리얼 판이고 진행 판은 그대로, 튜토리얼 뒤에는 409 → 중단하고 새로 시작. 튜토리얼 카드로 시작만 해도 완료. 회차 판은 가로채지 않음. 판 저장 뒤 완료 표시가 실패해도 같은 시작 UUID 재요청이 메움. 홈 안내 한 줄은 튜토리얼 전에만.
  - 첫 판 안내: 튜토리얼 완료 계정의 첫 실제 판은 첫 판 안내 꺼짐(`first_game` 거짓), 도움말 스위치·안내 줄 묶음은 남음. 칸 이전 계정의 첫 판은 켜짐.
  - 진척 칸 `tutorial_completed`: 비어 있으면 직렬화에서 빠지고 기존 문서는 미완료로 읽힘(`tests/engine/test_tutorial.py`). 실제 Mongo에서 표시 뒤 단서·결말·판 추가가 칸을 지우지 않는지는 `tests/infra/test_mongo_repo.py`에 더했지만, 이 기기에는 복제 세트가 없어 건너뜀.
