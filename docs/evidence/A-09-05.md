- 상태: 로컬 구현·증빙 작성 완료. 생성 기록의 프롬프트 전문·금지 지시는 B 확인 대기(아래 "트러블")
- 작성자(흐름): A
- 담당: E(11/9 PM 결정으로 D에서 변경)
- 작성일: 2026-11-09
- 환경: Windows 11, miniconda Python, 브랜치 task/A-09-05(base origin/dev 4e5c703). 정규화 도구는 표준 라이브러리와 저장소 `tools/assets`만 쓴다. 검수 그림 생성에만 저장소 밖에서 Pillow를 썼다.

## 명령

입력은 B(김영주)가 생성해 팀 공유 폴더 `2.asset 개선안 및 게임 UI 구성(김영주)/`에 올린 원본이다. `characters/`의 8장(793×1983 RGBA, 바탕 투명)과 `mascots/kkachi-v2.png`·`jokjebi-v2.png`(1254×1254 RGBA)를 저장소 밖 작업 폴더에 복사해 읽었다. 무당 여는 기본 `mudang_f.png`이고 변형(`-v2`·`-v3`·`-legacy-v4`·`-legacy-v5`)과 `branding/`은 쓰지 않았다.

```powershell
python -m tools.assets.normalize <원본 사본 폴더> --report <저장소 밖 JSON>
python -m tools.assets.make_placeholders
python -m tools.assets.check_assets --placeholder
python -m tools.assets.check_assets --allow-placeholder place,ui,map,ad
python -m unittest tests.assets.test_normalize
python -m tools.assets.preview_vn --bg meeting --id mudang_f --mode full --mascot kkachi --out <저장소 밖>
python -m tools.precheck --with-assets
```

처리 순서: 원본 RGBA 확인 → 인물별 머리카락 윗선(`normalize.HAIR_TOP`, 원본 좌표)과 보이는 발끝(알파 16 이상 경계 상자 아랫변)으로 단일 배율 계산 → 면적 평균 축소 → 512×1280 가운데·발끝 y=1248 배치(`cutout.fit_sprite`) → sprite 검사 → 무손실 PNG. 10장이 모두 규격을 통과한 뒤에만 파일·manifest를 쓴다. 마스코트는 단일 배율로 512×512 가운데, 발끝 기준선 y=480, 위 여백 32에 둔다(`normalize.fit_mascot`, 확대 없음).

머리카락 윗선: 갓이 없는 5명은 그림에서 보이는 머리카락 윗선(상투·뻗친 머리 끝은 장식으로 보고 뺐다)을 2배 확대 그림에서 읽었다. 갓을 쓴 3명(무당 여·남, 훈장)은 머리카락이 갓에 가려 있다. 갓 없는 5명의 (눈 − 머리카락 윗선) / (턱 − 눈) 평균 1.23을 눈·턱 위치에 적용해 추정했고, 갓 아래로 보이는 머리카락과 어긋나지 않는지 확인했다. 인물별 근거는 `tools/assets/normalize.py` 표 주석에 있다.

## 출력

- 실제 경로 덮어쓰기: `content/images/sprite/{mudang_f,mudang_m,hunjang,jumo,blacksmith,meosum,yakcho,gwabu}.png`, `content/images/mascot/{kkachi,jokjebi}.png`
- 파생 초상 8장: `content/images/portrait/<같은 id>.png`(`make_placeholders`, 등급별 크롭 위 y)
- manifest: 위 18개 항목 `placeholder: false`. 표정 변형 sprite·초상 48개는 임시 그대로다(A-10-06·A-11-04에서 이 기본 sprite를 편집 입력으로 쓴다)
- 생성 기록: `content/images/SOURCES.md` "A-09-05 실제 에셋" 절. 도구·모델·생성 시각은 원본 PNG의 콘텐츠 자격 증명(C2PA) 값(ChatGPT, gpt-image, 2026-11-06 14:03~14:40 UTC)이다. 서명은 검증하지 않았다
- 코드: `tools/assets/normalize.py`(새 도구), `tests/assets/test_normalize.py`(6개)
- 사람 검수용 그림(저장소 밖 `a0905_review/`): 8명 같은 축척 나란히(머리 꼭대기·눈·발끝 기준선), 파생 초상 8장, 마스코트 2장, 회의 배경(임시) 합성 4장
