## 스타일 가이드 검토
11/6 PM 결정(README 7절)으로 B 검수 대신 Claude 검토(PM 지시)와 Codex 교차검토(`codex exec -s read-only`)로 했다. 기준은 E-05-05 조건 4, 에셋1·5 정의(`docs/tasks/E_pm.md`), 규격표 `docs/assets/spec.md` 2·6·7·8·9절이다. 실제 그림은 아직 없어 문서만 봤고, 실제 그림의 판정은 11/11 E-11-10이다.

| 지적 | 출처 | 반영 |
|---|---|---|
| 4절: sprite는 손 소품 금지인데 주민 직업 표시에 "서책" | Claude | 직업은 옷·머리 장식으로만, 서책 → 도포 |
| 8절에 장면 배경(실제 필수) 항목 없음 | Claude | 5절 규칙으로 장면 배경 묶음 추가 |
| 시드·기준 그림: 7절은 도구 지원 시만, 8절은 무조건 | Codex | 8절을 "지원하면 기록, 아니면 그 사실 기록"으로 통일 |
| 나이를 "옷·머리 장식으로만" 드러낸다는 문구가 판정표의 주름 허용과 충돌 | Codex | 직업과 나이 표현을 나눠 씀 |
| 8절 허리선 "y=640 근처"가 spec 6절(y=640)과 다름 | Codex | y=640으로 통일 |
| 8절로 자세·손 소품·홍조·무당 30대·두 무복 같은 계열·마스코트 옷 금지를 판정할 수 없음 | Codex | 인물 sprite·마스코트 묶음에 항목 추가 |
| 표정이 구별되기만 하면 뜻이 뒤바뀌어도 통과 | Codex | 표정 id와 실제 표정의 뜻 일치 항목 추가 |
| 항목별 적용 유형이 모호(초상에 허리선, 불투명 배경에 투명 처리) | Codex | 체크리스트를 공통·인물 sprite·초상·표정·장면 배경·마스코트 묶음으로 나눔 |
| 같은 화풍 프롬프트 대상이 sprite·배경뿐이고 비교도 "다른 인물"만 | Codex | 7절 1번 대상을 모든 실제 파일로, 공통 항목 비교를 인물·배경·마스코트로 |
| 묶음별 적용으로 바꾸자 표정 변형 sprite가 인물 sprite 항목(색 번짐 등)을 빠져나감 | Codex(`codex review`) | 표정 변형 sprite는 인물 sprite 묶음도, 표정 초상은 초상 묶음도 보게 함 |
| 기준 그림을 지원하는 도구면 첫 sprite는 기준 그림이 아직 없어 통과할 수 없음(순환) | Codex(`codex review`) | 기준 그림이 된 첫 sprite는 "기준 그림 자신"으로 적게 함 |

수치 불일치(512×1280, 눈높이 y≈200, 발끝 1248, 얼굴 영역, 초상 크롭·먹남 `#2E344A`, 배경 크기)는 없었다(Codex 확인).
