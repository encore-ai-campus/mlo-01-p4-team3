# E-05-05 스타일 가이드·파일 규격·임시 에셋
- 상태: 로컬 사전 구현(미완). 사전 작업일: 11/4. 남은 것: 조건 4 검수자 B 확인(검수 대기). 공통 ①②⑧(PR 병합·필수 체크·PR 승인)은 원격 대기. B·D 인계는 PM 세션이 `pre/E-05-05`를 `master`에 통합한 커밋으로 한다.
- 커밋: (메인 커밋 예정)
- 작성자(흐름): E
- 환경: 로컬 Windows 11, Python 3.14.6(표준 라이브러리만), 작업 트리 `paldo-pre-assets`(브랜치 `pre/E-05-05`, master 0ecc49d까지 병합)
- 실제 소요 시간(h): 2.15
## 명령
```
python -m tools.assets.make_placeholders --force    # 임시 초상 교체 때 한 번(기존 단색 초상 13장이 protected_files로 잡혀서)
python -m tools.assets.make_placeholders --result
python -m tools.assets.make_placeholders --check
python -m unittest discover -s tests -t .
python -m unittest tests.assets.test_make_placeholders tests.assets.test_portrait_art
```

`--force` 없이 실행하면 `protected_files: 13`(커밋돼 있던 단색 임시 초상)과 `RESULT: MISMATCH`가 나왔다. 그래서 `--force`로 한 번 다시 만들었다. 보호 로직은 바꾸지 않았다.
