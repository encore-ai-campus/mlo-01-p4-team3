## 인계·제한

`python -m server.infra.outbox_publisher --kafka-config <보호 파일>`은 Django와 분리 실행한다. PALDO_MONGO_URI·TLS·ACL은 배포 호스트 전용으로 주입하고 검증 인증을 웹 서버에 복사하지 않는다. C-06-01의 outbox·committed_at·attempts를 사용하므로 선행 병합이 필요하다. 광고 발행기는 D의 MySQL Outbox 담당이고 여기서는 토픽을 제공한다.

게임 발행은 한 판씩 seq 오름차순, ack 뒤 표시, 장애 시 at-least-once이다. lease 만료 직후 지연 전송까지 Kafka 전역 순서를 보장하지 않으므로 소비자는 event_id로 중복 제거하고 판 순서는 seq로 해석한다. 서로 다른 토픽에는 전역 순서가 없다. poison 문서는 운영자 격리 전 해당 판을 막는다. claim은 마지막 임대 시각 기준으로 순환해 오류 판이 정상 판을 계속 굶기지 않으며 실제 Mongo 시험을 추가했다. 복수 호스트 fencing은 후속 작업이다.

p95는 소규모 검증의 ack 후 표시 시각까지 포함한 상한이며 게임 API 동시 부하 결과가 아니다. 중복 제거 계획은 sink commit과 함께 저장해야 하며 실제 Delta MERGE는 C-07-01에서 구현한다.
