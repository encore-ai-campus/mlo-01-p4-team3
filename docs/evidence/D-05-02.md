### 라이선스 확인 근거(2026-11-06)
- KoELECTRA: [해당 revision의 공식 모델 카드](https://huggingface.co/monologg/koelectra-base-v3-discriminator/blob/68b30cd259f34a4b5aa8786392612ba2a2617fcc/README.md)에 Apache-2.0이 명시되어 있고 API 메타데이터도 `apache-2.0`이다. [원본 프로젝트 LICENSE](https://github.com/monologg/KoELECTRA/blob/master/LICENSE)는 사용·수정·공개·배포 권한과 배포 조건을 규정한다. 가중치나 수정본을 재배포할 때 라이선스 사본, 관련 고지, 변경 표시 등 해당 조건을 보존한다.
- KLUE: [해당 revision의 공식 모델 카드](https://huggingface.co/klue/roberta-small/blob/b6b4c36d827e0293ae2fcf04d527072f10a23064/README.md)와 API 메타데이터에 개별 라이선스 표기가 없다(`model_card_license: null`). [공식 프로젝트 README](https://github.com/KLUE-benchmark/KLUE#license)에는 CC-BY-SA-4.0이 표시되어 있다. [CC의 공식 설명](https://creativecommons.org/licenses/by-sa/4.0/)에 따르면 해당 라이선스가 적용되는 자료는 상업 이용도 가능하고, 출처·변경 표시와 공유 시 동일조건 등을 따라야 한다. 다만 이것만으로 별도 모델 가중치의 이용 조건까지 확정하지 않아 이번 채택에서 제외한다. Apache-2.0으로 간주하지 않는다.

### 1 epoch 외삽 방법과 한계
- 데이터는 `fixtures/intent/seed_examples.jsonl`의 각 라벨 앞 4개씩 총 40문장이다. 자리표시자 P1/P2는 훈장/주모로 바꿨다. 데이터 SHA-256은 `a669565c6e2f0f1c54dc04d6fcca5e88a6205136c6c2f466249087a036ecb261`다.
- 두 모델 모두 사전학습 인코더 전체와 새 10라벨 분류 헤드를 학습했다. seed=7, AdamW(lr=2e-5, foreach=False), 배치 4, 길이 64, 10 step이다. loss의 유한성도 확인했다. 분류 헤드는 새로 초기화했으며 이 표본 시험은 정확도 평가나 정식 미세조정 완료를 뜻하지 않는다.
- 전처리 시간/문장 `p`, 첫 step 실측 `t0`, 이후 9 step 평균 `t`를 사용한다. `1 epoch 예상(ms) = N*p + t0 + (ceil(N/4)-1)*t`다. 모델 다운로드·로드·옵티마이저 생성·평가·체크포인트 저장 시간은 제외한다. 마지막 불완전 배치에도 전체 배치 시간을 적용하므로 소폭 과대 추정할 수 있다.
- KoELECTRA 첫 step 1622.669 ms, 이후 평균 1365.280 ms. KLUE 첫 step 662.393 ms, 이후 평균 709.052 ms다. 전처리 원시값과 step별 시간은 로컬 `mlruns/intent_candidates/<후보>/run.json`에 있다.
- 50·200·1,000문장 예상치는 동일 길이·배치·장비·부하라는 가정이다. P-14의 최종 학습 규모가 미확정이므로 200·1,000을 확정 데이터 크기로 사용하지 않는다. 실제 문장 길이, VM 자원, 부하가 달라지면 재측정한다.
- 후보마다 새 프로세스를 사용했다. 메모리는 Windows GetProcessMemoryInfo의 WorkingSetSize/PeakWorkingSetSize이며, torch·tokenizer·모델을 포함한 프로세스 RSS다. 추론 최대 RSS는 로드 단계도 포함하고, 학습 최대 RSS는 그 뒤 학습 단계까지 포함한다. 가중치 파일 크기나 시스템 전체 RAM 사용량과 다르다. 이 값은 Windows 호스트 실측이며 배포 VM 성능을 보장하지 않는다.
