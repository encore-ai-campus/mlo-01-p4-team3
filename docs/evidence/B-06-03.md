SQLite 시험에서 MySQL 동시성·스키마 시험 3개를 건너뛰었다.

htmx 폼 시작 회귀 시험은 수정 전 302 응답으로 실패했고, 수정 후 200과 `meeting.html` 조각을 확인했다. CSRF가 없으면 403이며, 같은 폼 재요청은 기존 판과 시작 이벤트 하나를 유지한다. SQLite 출력은 `out/handoff/htmx-start-after.log`에 있다. 아래 MySQL·Mongo 시험은 구현 커밋 `920c585`에서 다시 실행했다.
