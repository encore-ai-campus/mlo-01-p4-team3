## 11/11 운영 읽기 접근 확인

기존 SSH 설정으로 Spark 호스트에 접속했다. 광고 설정 경로는 기존 D-08-02 로컬 스크립트의 참조를 사용했다. 인증값과 보호 경로는 기록하지 않았다.

```sh
ssh <기존 Spark SSH 별칭> 'sudo -n true'
ssh <기존 Spark SSH 별칭> 'sudo -n -l'
# 해당 설정 파일에 sudo -n cat을 적용하고 표준출력은 프로세스 내부에서만 처리했다.
```

출력 발췌는 다음과 같다.

```text
sudo: interactive authentication is required
{"sudo_config_read_exit": 1, "sudo_authentication_required": true, "sudo_config_readable": false}
{"readable_pipeline_configs": []}
```

SSH 접속은 성공했고 설정 파일의 상위 디렉터리는 현재 계정으로 탐색할 수 없었다. 비대화형 sudo 읽기는 인증을 요구했다. 읽기 가능한 프로젝트 폴더와 기존 클라이언트 설정을 확인했으나 운영 조회에 사용할 설정을 확보하지 못했다. 당시 사람 광고 수치는 미확인이었다. 이후 사용자가 자신의 SSH 터미널에서 sudo 인증 후 아래 조회를 실행했다.

## 사용자 sudo 실행과 공식 Bronze 원본 확인

사용자가 자신의 인증된 SSH 터미널에서 `sudo python3 /tmp/d1004-human-ads-readonly-20261111.py`를 실행했다. 비식별 집계 `d1004-human-ads-summary.json`을 SSH로 회수해 대조했다.

- 공식 Bronze v245의 정식 테스트 시간대 원본 이벤트는 serve 73건, impression 5건, click 4건이다. 모두 `source=human`, `load_test=false`다. [결과 JSON](perf/D-10-04/human_bronze.json)
- 기존 조회의 v129 마지막 커밋은 `2026-11-09T22:02:05`(Spark 반환값, 시간대 표기 없음)다. 18:00 이전에 Delta에 커밋된 버전만 선택해 테스트 전 버전을 읽었으며, 뒤에 적재된 테스트 시간대 이벤트는 v245에서 확인됐다.
- 0건은 v129의 과거 저장 상태로 기록한다. 이후 v245 고정과 서버 수신 시각 컷오프를 적용한 재조회가 성공했다. 참가자 코호트 연결은 미확인이다.

## 운영 사람 광고 판정 집계

사용자가 실행한 명령은 `sudo python3 /tmp/d1004-human-ads-readonly-v245.py`다. 결과 `d1004-human-ads-summary-v245.json`을 SSH로 회수했다. 공식 Bronze v245와 서버 수신 컷오프 11/10 18:00 KST를 적용했다. 회수 파일의 지면별 건수 합계, 전체 건수, 수신 시각 분류와 원본 건수를 대조했다.

```json
{"impressions": 5, "clicks": 4, "invalid_impressions": 0, "invalid_clicks": 0, "pending_events": 0}
```

전체 serve 73건 중 47건이 채워졌다. 로비는 serve 52/filled 31/유효 노출 4/클릭 4, 결과는 11/8/1/0, 복기는 10/8/0/0이다. 모두 무효·보류 0건이며 연결되지 않은 시간대 이벤트도 0건이다. [측정 JSON](perf/D-10-04/human_ads.json)

최초 v245 조회는 설치된 구버전 `gold_rows`에 `invalid_impressions` 반환 필드가 없어 실패했다. 실제 서버의 `ads_contract.py`를 읽어 같은 KeyError를 로컬에서 재현했다. 기존 `silver_rows` 판정 결과에서 종류별 무효 건수를 직접 세도록 수정했다. 클릭 유도 노출 1회, 중복 이벤트 제거, 마감 경계, 무효 노출·클릭 양수 사례를 서버 설치 버전과 최신 로컬 버전에서 확인했다. 수정본 해시를 확인한 뒤 사용자가 같은 명령을 재실행해 위 결과를 얻었다. 운영 Delta는 조회만 수행했다.

집계 범위는 계약의 출처 필드에 따른 해당 시간대 사람 광고다. 참가자 명단 및 개별 판 연결은 미확인으로 보고했다.

## 판 범위 재판정 전 로컬 검증

아래 검사는 조건 1을 시간대·출처로 판정했을 때의 기록이다. 이후 광고 이벤트를 18:00 스냅숏에 포함된 사람 판으로 한정할 근거가 부족해 조건 1을 미충족으로 정정했다.

