## 1. 배경과 사업 문제

팔도무록은 **신규 웹게임 사업의 파일럿(MVP)**이다. 파일럿 개발 스프린트(2026-11-05~11-12, 5명)에서 게임, 데이터 수집·학습·서빙, 광고 수익 구조, 운영 체계를 한 서비스로 만든다. 스프린트 끝에 사업 의사결정자가 사업 검토 데모와 저장소를 보고 출시 여부를 판단한다. 그래서 동작과 수치의 근거가 저장소 안에 남아 인수인계와 감사가 가능해야 한다.

이 파일럿이 풀어야 할 사업 문제는 다음과 같다.

1. **초기 이용자가 적어도 서비스가 성립해야 한다.** 동시 접속자를 모으지 않아도 한 판이 성립하는 싱글플레이 사회적 추론 게임으로 시작한다. 봇 시뮬레이션으로 대량 데이터를 만들고, 소수의 사람 판으로 검증·보정한다.
2. **AI가 제품 차별점이 되어야 한다.** 자유 입력은 의도 해석 모델이, NPC의 말투는 로컬 LLM이, NPC의 판단은 씐 자 확률 모델이 맡는다. 각 모델은 기준선과 비교한 수치로 효과를 보여야 한다.
3. **이용 데이터가 서비스 품질로 돌아와야 한다.** 사람 데이터는 적으므로 의도 해석기 재학습, 상대 봇 보정, 밴딧으로 반영하고, 승격은 평가 관문을 통과할 때만 한다.
4. **무료 서비스의 수익 구조가 실제로 동작해야 한다.** 무료 플레이에 광고를 붙이고, 경매·과금·예산·무효 판정·대사가 맞게 돌아가는지 확인한다. 실제 광고주를 모으기 전이므로 파일럿에서는 시범 운영 소재와 합성 트래픽으로 검증한다.
5. **운영비를 낮게 유지해야 한다.** GPU 없이 기존 노트북 5대 위의 VM 20대로 개발·내부 테스트를 하고, 외부 유료 API를 쓰지 않는다. 데모와 외부 공개는 계정별 6만 원 한도의 AWS로 한다.

출시 여부를 정한 뒤 외부 공개 서비스에서 측정한다. 파일럿의 합격선이 아니다.

## 4. In scope

- **게임**: 싱글플레이 사회적 추론 게임. 플레이어는 항상 무당이다. 행적 진술 대조, 점괘, 기색, 캐묻기, 고백, 비밀 투표·결선, 원한 단서와 퇴마·한풀이 결말. 인원 프리셋(5/1, 6/1 기본, 7/1, 8/1, 9/2, 11/2) 중 공개 기준을 통과한 것만 연다.
- **NPC**: 네 층 상태, 결정론적 엔진 결정, 씐 자 확률 모델, 템플릿 대사 + 추궁 답변의 LLM 표현.
- **입력**: 자유 입력(BERT 계열 의도 해석 + 규칙 매칭, 발언 카드 확인)과 버튼 입력.
- **웹**: Django 템플릿 + htmx + Alpine.js 화면(회의, 진술표, 수첩, 결과, 복기), 판 종료 설문.
- **계정**: 개인 로그인 ID·비밀번호로 가입·로그인(모든 게임 화면·API 로그인 필수). 엄격한 비밀번호 규칙, 연속 실패 잠금, 관리자 초기화. 이름·연락처·이메일은 받지 않고, 게임 데이터에는 계정별 가명 ID만 쓴다(11/4 결정, 공개 가입, `BR-OQ-022`).
- **데이터·ML**: 이벤트 아웃박스 → Kafka → Spark → Delta Lake, 봇 시뮬레이션, MLflow 레지스트리, 재학습 평가 관문, 카나리아, 밴딧.
- **LLM**: 로컬 CPU llama.cpp + LangGraph(추궁 답변 표현).
- **광고(수익원)**: 시범 운영 소재 캠페인, eCPM 경매(2등 가격), 예산 예약·확정·해제, 노출·클릭 유효 판정, 건별 대사, 합성 트래픽 검증, 수익 지표 집계(채움률·eCPM·소진율·무효율). 지면 4곳.
- **인프라·운영**: 노트북 VM 20대(개발·내부 테스트), AWS(데모·외부 공개), Prometheus·Grafana, 구조화 로그, 장애 복구 시험.
- **콘텐츠·에셋**: 창작 설정(설화 원전 미인용), 생성형 AI로 미리 만든 도트(픽셀 아트) 이미지(생성 기록 포함).
- **사용자 테스트**: 내부망 30명 목표, 설문, 결과 보고.
- **파일럿 산출물**: 저장소(코드·계약·증빙), 사업 검토 데모 자료(25분).

## 6. 업무 규칙·제약·가정

**제약**
- `BR-CON-001`: 파일럿 개발 스프린트는 2026-11-05~11-12, 5명이고 1인 하루 9시간(PM 10.5시간)이다. 범위는 줄이지 않고, 계약 선확정·가짜 구현·인수 시점 앞당기기로 대응한다.
- `BR-CON-002`: 서버는 GPU 없는 노트북 5대(i5-1340P, RAM 32GB) 위의 VM 20대다. LLM은 노트북 3에 둔다. 외부 유료 API는 쓰지 않는다.
- `BR-CON-003`: AWS 비용은 계정별 1인 6만 원 한도다. 사용하는 모든 계정에 예산 알림을 걸고 데모 후 종료 절차를 실행한다.
- `BR-CON-004`: 게임은 무료 플레이이고 수익원은 광고다. 파일럿에서는 시범 운영 소재로만 광고를 내고 실제 결제·정산은 하지 않는다. 광고는 회의·투표·밤 화면에 넣지 않는다.
- `BR-CON-005`: 승패·진실·의심도는 결정론적 엔진만 정한다. LLM은 상태를 바꾸지 않고 사실을 더하지 않는다. LLM 문장은 게임상 증거가 아니다.
- `BR-CON-006`: 개인정보는 가명 UUID만 쓴다. 원문 입력은 마스킹 후 저장하고 2026-12-12에 삭제한다. 접속 정보와 비밀정보는 저장소·공유 문서·채팅에 쓰지 않는다.
- `BR-CON-007`: 성능 수치는 계측값만 인정하고, 동작하는 구성요소는 모두 구조화 로그를 남긴다.
- `BR-CON-008`: 모델 교체는 평가 관문을 통과할 때만 한다. 모델 버전은 판 시작 때 고르고 판이 끝날 때까지 고정한다. 사용자 테스트에서는 카나리아를 끄고, 그 밖의 적용·승격·롤백은 카나리아 계약(`contracts/ml_lifecycle.md` 4절)을 따른다. 업데이트는 게임 안에 공개한다.
- `BR-CON-009`: 비교 대상 그노시아의 규칙·캐릭터·용어를 베끼지 않는다(부록 1의 차별점 유지).
- `BR-CON-010`: 원격 저장소는 조직이 만들어 팀을 초대하는 공개 저장소다(P-11). 초대를 받기 전까지 로컬 커밋만 한다. GitHub 푸시와 이슈 생성은 PM의 명시적 허가가 필요하다.

**가정**
- `BR-ASM-001`: 기존 VM 20대가 11/5에 기동되고, 기록된 소프트웨어 버전이 실측과 크게 다르지 않다(11/5 실측으로 확인).
- `BR-ASM-002`: 3~4B급 CPU 양자화 모델로 추궁 답변 p95 15초 안에 들어온다(11/5~11/6 벤치로 확인).
- `BR-ASM-003`: 내부망 참가자 30명을 모을 수 있고, 같은 사람이 여러 판을 한다.
- `BR-ASM-004`: 봇 시뮬레이션 데이터로 학습하고 사람 데이터로 검증·보정하는 방식이 소수 참가자 조건에서 유효하다.
- `BR-ASM-005`: 합성 트래픽 검증은 알고리즘·회계·제어 루프가 설계대로 동작하는지만 증명한다. 실제 광고 성과는 증명하지 않는다.
- `BR-ASM-006`: 이미지 생성 도구의 이용 조건이 공개·상업 사용을 허용한다(P-10에서 확인).
- `BR-ASM-007`~`011`: 시장 가정(1.2절).

- 한국 민속 분위기의 창작 설정이다. 설화 원전은 인용하지 않고, 그노시아의 규칙·캐릭터·용어를 쓰지 않는다.
- LLM은 로컬 CPU 모델이고 말투 표현에만 쓴다. 사실과 판정은 엔진이 정하고 LLM은 상태를 바꿀 수 없다. 외부 API 호출 요금이 없고, 표현 단계의 사실 왜곡은 검증기·폴백·사람 검수로 줄인다.
- 가격 구조: 무료 플레이 + 광고 수익. Wolvesville은 무료 + 선택 구매, 앞의 두 게임은 유료 1회 구매다.

### 부록 2. 서비스 운영 정책

1. **가격 정책**: 무료 플레이. 파일럿에는 결제 기능이 없다. 유료 확장은 향후 검토한다.
2. **수익 모델**: 광고. CPC·CPM 캠페인, eCPM 순위 2등 가격 경매. 금액은 정수 밀리원으로 계산한다. 파일럿에서는 시범 운영 소재(가상 광고주 캠페인)만 내고 실제 돈은 오가지 않는다.
3. **광고 지면**(4곳, 몰입을 깨지 않는 곳만)

   | 지면 | 위치 | 규격(px) |
   |---|---|---|
   | `lobby_banner` | 로비 | 728×90 |
   | `result_banner` | 판 결과 화면 | 728×90 |
   | `llm_wait` | LLM 답변 대기 | 300×250 |
   | `review_side` | 복기 화면 옆 | 300×250 |

   회의·투표·밤 화면에는 광고를 넣지 않는다. 광고에는 "광고" 표시를 하고, 파일럿의 랜딩은 사이트 안 가상 경로다.
4. **이용 대상과 기간**: 파일럿(11/5~11/12)에는 내부망 테스트 참가자. 출시가 결정되면 도메인을 붙여 AWS로 외부 공개한다(일정 미정).
5. **식별과 개인정보**: 사용자는 직접 만든 로그인 ID·비밀번호로 가입·로그인한다. 가입 때 가명 UUID를 발급해 계정에 저장하고, 게임 데이터에는 가명 ID만 쓴다. 이름·연락처·이메일은 받지 않는다. 가입 화면의 수집 고지에 동의해야 가입할 수 있다(11/4 결정).
6. **보관과 삭제**: 원문 입력은 마스킹 후 저장한다. 2026-12-12(파일럿 종료 + 30일)에 원문을 포함해 가명 ID가 붙은 모든 사용자 테스트 데이터(라벨·특징·추출 데이터셋 포함)를 삭제한다(11/4 결정, C-09-02). 화면 아래의 가명 ID로 삭제를 요청할 수 있다. 출시 후 보존 기간은 출시 전에 다시 정한다(`BR-OQ-019`).
7. **업데이트 공개**: 모델·전략 업데이트는 판 시작 때 버전을 정해 판이 끝날 때까지 고정하고(`BR-CON-008`), 게임 안에 공개한다(세계관상 "창귀가 무당들의 수법을 기억했다").
