## 1. 배경과 현재 문제

부트캠프 4차 프로젝트(2026-11-05~11-12, 5명)는 데이터 수집·학습·서빙·운영을 한 서비스 안에서 끝까지 보여 줘야 한다. 평가는 강사가 GitHub 저장소를 검토하는 방식이고, 필수 제출물은 발표 자료(25분)와 저장소다. 그래서 동작과 수치의 근거가 저장소 안에 남아야 한다.

이 조건에서 풀어야 할 문제는 다음과 같다.

1. **데이터가 생기는 서비스가 필요하다.** 동시 접속자를 모으지 않아도 한 판이 성립해야 하고, 사람이 적어도 학습·검증할 데이터가 나와야 한다. 싱글플레이 사회적 추론 게임은 봇 시뮬레이션으로 대량 데이터를 만들고, 소수의 사람 판으로 검증·보정할 수 있다.
2. **LLM과 ML의 쓰임이 분명해야 한다.** 자유 입력은 의도 해석 모델이, NPC의 말투는 로컬 LLM이, NPC의 판단은 씐 자 확률 모델이 맡는다. 각 모델은 기준선과 비교한 수치로 효과를 보여야 한다.
3. **사용자 데이터가 서비스에 다시 반영되는 루프가 있어야 한다.** 사람 데이터는 적으므로 의도 해석기 재학습, 상대 봇 보정, 밴딧으로 반영하고, 승격은 평가 관문을 통과할 때만 한다.
4. **수익 구조를 실제 결제 없이 보여 줘야 한다.** 무료 게임에 가상 광고주가 입찰하는 광고를 붙이고, 노출·클릭 집계가 다시 입찰에 반영되는 루프와 회계 정합성을 합성 트래픽으로 검증한다.
5. **자원 제약이 크다.** 서버는 GPU 없는 노트북 5대 위의 VM 20대이고, 외부 유료 API를 쓰지 않는다. 시연과 외부 공개는 계정별 6만 원 한도의 AWS로 한다.

## 4. In scope

- **게임**: 싱글플레이 사회적 추론 게임. 플레이어는 항상 무당이다. 행적 진술 대조, 점괘, 기색, 캐묻기, 고백, 비밀 투표·결선, 원한 단서와 퇴마·한풀이 결말. 인원 프리셋(5/1, 6/1 기본, 7/1, 8/1, 9/2, 11/2) 중 공개 기준을 통과한 것만 연다.
- **NPC**: 네 층 상태, 결정론적 엔진 결정, 씐 자 확률 모델, 템플릿 대사 + 추궁 답변의 LLM 표현.
- **입력**: 자유 입력(BERT 계열 의도 해석 + 규칙 매칭, 발언 카드 확인)과 버튼 입력.
- **웹**: Django 템플릿 + htmx + Alpine.js 화면(회의, 진술표, 수첩, 결과, 복기), 판 종료 설문.
- **데이터·ML**: 이벤트 아웃박스 → Kafka → Spark → Delta Lake, 봇 시뮬레이션, MLflow 레지스트리, 재학습 평가 관문, 카나리아, 밴딧.
- **LLM**: 로컬 CPU llama.cpp + LangGraph(추궁 답변 표현).
- **광고**: 가상 광고주 캠페인, eCPM 경매(2등 가격), 예산 예약·확정·해제, 노출·클릭 유효 판정, 건별 대사, 합성 트래픽 검증. 지면 4곳.
- **인프라·운영**: 노트북 VM 20대(개발·내부 테스트), AWS(시연·외부 공개), Prometheus·Grafana, 구조화 로그, 장애 복구 시험.
- **콘텐츠·에셋**: 창작 설정(설화 원전 미인용), 생성형 AI로 미리 만든 이미지(생성 기록 포함).
- **사용자 테스트**: 내부망 30명 목표, 설문, 결과 보고.
- **제출**: 저장소(코드·계약·증빙), 발표 자료 25분.

## 5. Out of scope

- 실제 결제, 유료 아이템, 실제 광고주·실제 광고 집행과 정산
- 모바일 앱, 동시 접속 멀티플레이
- GPU 사용, 외부 유료 API(LLM 포함)
- 설화 원전의 인용, 실존 인물·상표가 들어간 이미지
- 플레이어가 씐 자를 맡는 모드(MVP 이후 확장)
- 플레이어 몰래 하는 난이도 조절, 개인별 비공개 난이도
- 재방문율 지표(4차에서는 측정 목표로 두지 않는다)
- 사람 행동 예측 모델(이탈 예측, 사람 모방 봇)
- 외부 공개용 도메인 연결과 운영(시연 이후 일정. 이번 기간에는 AWS 시연까지)

## 6. 업무 규칙·제약·가정

**제약**
- `BR-CON-001`: 기간은 2026-11-05~11-12, 1인 하루 9시간(PM 10.5시간)이다. 범위는 줄이지 않고, 계약 선확정·가짜 구현·인수 시점 앞당기기로 대응한다.
- `BR-CON-002`: 서버는 GPU 없는 노트북 5대(i5-1340P, RAM 32GB) 위의 VM 20대다. LLM은 노트북 3에 둔다. 외부 유료 API는 쓰지 않는다.
- `BR-CON-003`: AWS 비용은 계정별 1인 6만 원 한도다. 사용하는 모든 계정에 예산 알림을 걸고 시연 후 종료 절차를 실행한다.
- `BR-CON-004`: 게임은 무료다. 수익 모델은 가상 광고주의 광고 수익으로만 보이고, 실제 결제는 넣지 않는다. 광고는 회의·투표·밤 화면에 넣지 않는다.
