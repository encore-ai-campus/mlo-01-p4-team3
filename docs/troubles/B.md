# B 웹·API 트러블 기록

### B-05-01

- 문제는 초기 worktree에서 Django를 시작하려면 다른 태스크에 배정된 모듈이 필요하다는 점이었다.
- 원인은 통합 설정과 URL 목록에 계정, 화면, 운영자 세션 등록이 함께 들어 있던 것이다.
- Django 골격 설정과 상태 확인 경로 3개를 분리했다. 골격의 `/readyz`는 DB 준비 상태를 확인한다. 게임 서비스 조립 후에는 해당 서비스도 준비 판정에 포함한다.
- SQLite Django 테스트 2개가 통과했다. 로컬 MySQL 연결 설정으로 세 상태 확인 경로에서 모두 200과 요청 ID를 확인했다.
