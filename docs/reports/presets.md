# 프리셋별 개발 평가 리포트

11/11 dev `098b077`의 `rule-0.8.decision-2`, `content-1.1`에서 필수 프리셋 네 종을 각각 500판 측정했다. NPC는 `rule-v0`, 플레이어는 `player-logic-v0`, 판 진행의 추정 층은 `fake-suspicion-1`이다. 판 시드는 실행 시드 × 1,000,000 + 판 순번이며, 구간은 Wilson 95%다.

난이도는 LogicBot 기준 마을 승률로 분류했다. 60% 초과는 마을 우세, 40~60%는 균형 범위, 40% 미만은 마을 열세다. 5·7·8인의 P-08 개발 판정에는 이 범위와 일수·배정·완주 결과를 사용했다. 6인 공식 기준은 A-10-01의 보정 알리바이 봇·모델 v0 결과가 필요하다. 공개 여부는 PM이 최종 결정한다.

무감금 상한은 매일 밤 마을 주민 한 명이 실종되고 G≥V+M에서 종료되는 규칙으로 계산했다. 씐 자 1명인 필수 프리셋은 1일째 활동 인원 N에 대해 마지막 날이 N−2다. `tests/test_preset_report.py`에서 content-1.1과 실제 엔진을 사용해 매일 일반·결선 투표가 동점으로 끝나는 경로를 재현했고 감금 없이 각각 3·4·5·6일째에 종료했다.

미학습 조합 평가는 고정 모델 `suspicion-logistic-9bbee626f29b`를 사용했다. 공식 학습 입력 SHA-256을 대조한 뒤 fit 2,730판과 온도 보정 dev 585판의 프리셋별 비밀 보유자·비밀 ID 조합 425개를 제외했다. 종료 진실은 조합 필터와 정답에만 사용했다.
