# D-10-02 구현 계획

- C-08-02 확정 맥락 집계의 귀속일을 기준으로 시간 순서 분할한다. 동일 평가 행에 베타와 LightGBM의 노출 가중 로그 손실·ECE를 적용한다. 시나리오 6의 확률 정답은 예측 채점에만 사용한다.
- 통과 모델을 격리 MLflow에 등록한다. 광고 서버는 60초 캐시에서 맥락별 점수를 읽고 요청을 카나리아와 대조로 나눈다. 악화 신호 뒤 같은 MySQL 경로로 베타로 복귀하는지 아웃박스에서 확인한다.
- 페이싱은 기존 5분 주기와 조정 폭을 지키며 목표 추종 이득을 보정한다. 시나리오 1의 기존 세 시드를 다시 실행한다.
- 확정 gold 비용과 유효 클릭으로 CPC 입찰가를 계산한다. 광고주 하한·상한, 입찰 스냅샷 재시도, 캐시 재적재, 실제 serve·후속 이벤트를 검사한다.
- 조건별 실측과 미검증 범위를 증빙에 적고 사전 검사와 완료 검사를 실행한다.
