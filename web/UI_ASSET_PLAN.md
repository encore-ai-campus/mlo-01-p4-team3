# 공식 UI 에셋 인수 계획

최신 계약(PR #304)은 시안의 색·창 틀만 참고하고 시안 이미지·글꼴을 정식 UI에 가져오지 않는다. 전체 시안은 별도 보존 worktree이며 신규 브랜딩 발주는 이번 범위에서 제외한다.

| 순서 | 대상 | 조치·담당 |
|---|---|---|
| 완료 | 여성 무당 전신·초상 | 사용자 확정 v5 적용. 원본은 보존본, 공식 ID·규격 유지 |
| 확인 | 다른 7인 전신·초상, 까치·족제비 | A-09-05 등록 원화 유지. 전체 재생성 대신 배경과 합성 후 필요한 부분만 리터칭 판정 |
| 우선 | 회의·밤 2개 | A-10-05 E 정규화/인수. 낮 마당·밤 하늘/지붕, 인물/글자 없음·중앙/하단 비움·장소 강조 금지 |
| 후속 | 표정24·파생초상24 | A-10-06 담당의 실제 기본 sprite에서 얼굴만 편집. 여성은 v5 해시 사용, E B-10-07 연출 연결 |
| 후속 | 추가5인·초상5 | 기존 태스크/인물 풀 일정대로 인수, 숨은 역할별 외형 금지 |
| 별도 승인 | 제목·호랑이·opening·한지 이미지 | 보존 시안에서만 검토. 이번 PR/정식 화면에는 포함하지 않음 |

현재 등록18·임시84이며 기본 전신8·초상8·동물2가 등록됐다. 배경도 임시 상태다. 소스 경로·가공·출처는 content/images/SOURCES.md, 기준은 docs/assets/spec.md·style_guide.md를 따른다. 등록은 최종 미술 합격이 아니다.

리터칭 전 대표 인물·배경·동물을 나란히 보고 선 굵기·광원·피부·털/깃털 표현을 조율한다. 여성 v5를 다시 선택하게 하지 않는다. 까치 무장신구, 족제비 붉은 끈의 작은 놋쇠 방울1개와 역할을 유지한다. 기본 수정 시 실제 표정/초상·해시·출처도 함께 갱신한다. 자동 규격 검사 후 별도 미술 검수자가 판정하며 A-09-05·A-10-05는 PM의 검수자 지정이 필요하다.
