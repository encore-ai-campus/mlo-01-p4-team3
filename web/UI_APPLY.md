사용자가 PC는 시안처럼 페이지 전체 스크롤 없이 보이도록 요청했다. 폭 900px 이상 계정·홈의 머리글·본문을 100svh 안에 넣고 긴 내용은 창 안에서 읽도록 바꿨다. 인증 후 홈은 제목·안내와 하단 가명 ID·단서·로그아웃을 유지하고 시작 설정 영역만 내부 스크롤한다. 모바일은 자연스러운 문서 흐름과 글자 크기를 유지한다. 이 절이 아래 이전 스크롤 수치·배치 설명보다 최신이다.
