# 최신 계약 UI 검증

현재 기준은 dev 62e7525(PR #304)다. 전체 시안은 별도 보존 브랜치 e22034e로 분리했고 정식 PR에는 해당 이미지·글꼴 파일을 가져오지 않았다. 원본 B-ui-design·단일 HTML도 그대로다.

## 현재 구현

- 기본 vn/classic 되돌림, 모드별 캐시 및 meeting_classic.html·meeting_parts 기록 공유.
- theme.css 공통 색·시스템 글꼴, 공식 manifest 이미지. 여성 전신·초상은 사용자 확정 v5.
- 900px 이상 하단25% 대사창·x860 이후 선택지, 미만은16:9 무대 아래 같은 #meeting의 대사·선택지.
- 모두 보기 자동 펼침·전신 건너뛰기 종료·재조회·저장소 차단 메모리 보존, 기존 명령·개인정보·설문 유지.
- 호랑이·창귀 제목·시안 이미지/폰트 제외. 첫 등장·추방/처형·엔딩 전신·표정은 E 잔여, 전체 완료 아님.

## 검증

서버261건·47.447초 통과(환경 의존4건 제외). Chrome6인 실제 폼12명령·8인15화면, 데스크톱1280/모바일360·CSS200%, 반응형 부모 위치·비율·같은 판 종료 탭·5단계 확신도·설문·기록/지도/수첩을 확인했다. 가로 넘침·깨진 이미지·페이지/콘솔 오류·예상치 못한 HTTP 실패0. Browser plugin not available로 설치된 Chrome/Playwright를 썼다.
