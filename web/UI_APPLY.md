# UI 적용과 검증 범위

현재 B-10-08 로컬 구현은 dev `51e17f6`를 반영한다. PR #311의 VN 부분 인계와 PR #314의 시안 적용 허용 결정 위에 계정 화면·공통 글꼴을 적용하고 PR #323의 정식 밤·회의 배경을 인수했다.

## B-10-08

로그인·가입·홈 배치, 창귀 제목·탭 제목, 공식 호랑이 로고, 공통 글꼴을 적용했다. 기존 동의·오류·비밀번호 안내·회차·일반 판 시작·이어 하기·판 메타·명령 재전송은 보존한다. 게임 화면의 호랑이 비노출은 녹화 단계 전체의 서버 시험과 실제 브라우저의 회의·밤으로 확인한다.

`ui_theme_preview --font-probe`를 명시했을 때만 시험 미들웨어가 로그인 문서의 Navigation Timing·글꼴 Resource Timing을 숨김 DOM에 기록한다. `tools/perf/account_assets.py`는 표본과 로컬 WOFF2 크기를 공통 결과 JSON으로 저장한다. 운영 템플릿·미들웨어·API에 계측을 넣지 않는다. 수치는 로컬 첫 화면 표본이며 VM 성능 합격 기준으로 사용하지 않는다.

## 시안과의 차이

| 비교 항목 | 판정·사유 |
|---|---|
| 제목·로고·글꼴 | 확정 시안과 같은 이름·선택 원화·서체. 로고는 공식 규격 정규화본 |
| 배색·배치·창 | 1280px 로그인에서 왼쪽 x120/y133·488×470, 오른쪽 x672/y147 부근. 간격 64px·제목 66px·입력창 46px·버튼 44px와 안내 순서를 보완. 원본 종이 결 이미지는 E/PM 정식 등록 잔여 |
| 로그인·가입 문구 | 시안 전용 경고·‘화면 확인’ 버튼을 실제 로그인·동의·오류·가입 기능으로 대체 |
| 비로그인 홈 | 사용자 요청에 따라 게임 소개 → 가입/로그인 → 시작 방법 3단계. 로그인 양식은 기존 `/accounts/login`에 유지 |
| 로그인 뒤 홈 | 일반 게임/배정된 테스트 참여를 하나씩 펼침. 배정된 미완료 판이 있으면 테스트, 없거나 모두 완료면 일반 게임을 먼저 표시. URL·POST 필드·시작 정책 유지 |
| 메뉴 | B-10-08의 도움말·로그인·가입 메뉴를 유지. 로그인 뒤는 기존 시작 메뉴 |
| 밤 그림 | PR #323의 공식 night 사용. 보존한 HTML의 로그인 CSS 그림(큰 달이 있는 장면)과 공식 night(더 어두운 마을)의 외형은 다름. 태스크가 공식 night를 명시하므로 임의 교체하지 않고 PM에게 기준 버전·로그인 그림 확인 요청. 임시 대체 그림·옵션 제거 |
| 모바일 | 900px 미만 계정은 한 열, 게임은 기존 확정 16:9 무대 아래 대사·선택지 유지 |
| 첫 화면 버튼 | 599px 이하 가입/로그인 버튼은 세로 한 열. 360px에서 긴 가입 문구가 한 글자만 다음 줄로 떨어지던 문제를 보완 |
| classic | 장애 복귀용 계정 배치를 보존하고 제목·글꼴만 변경. 기본 VN 계정은 시안 적용 |

기능 시험 통과는 완성 시안 전체의 외형 일치를 뜻하지 않는다. 빈 그림과 잘린 임시 글자 문제는 정식 배경 인수로 해소했다. B-10-08은 계정 UI·공통 글꼴 범위이며 게임의 창·조작 패널 전체를 옮긴 작업으로 설명하지 않는다. [PM 전달 사항](PM_UI_REVIEW.md#pm에게-전달할-내용)과 [E 인수 항목](UI_ASSET_PLAN.md#e에게-전달할-작업)을 구분했다.

## 이전 VN 인계

PR #311은 기본 vn/classic 복귀·읽기 상태·공개 기록/명령 공유·여성 v5를 부분 인계했다. 당시 1,215개 사전검사 결과는 [B-10-07 증빙](../docs/evidence/B-10-07.md)과 PR 본문의 과거 기록이다. 현재 B-10-08 전체를 같은 수치로 검증했다고 표현하지 않는다. 최신 명령·수치·한계는 [B-10-08 증빙](../docs/evidence/B-10-08.md)에 기록한다.
