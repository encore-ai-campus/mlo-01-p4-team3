# PM 인계: 창귀 계정 디자인과 전체 시안 일치

B-10-08을 dev `51e17f6`(정식 배경·BERT 사전 검증·삭제/보존 갱신 반영) 위에 구현했다. 계약·기획 원문은 수정하지 않았다. 이 문서는 PM에게 전달할 검토 사항이며 E의 구체적 잔여는 [E 인수 문서](UI_ASSET_PLAN.md#e에게-전달할-작업)로 나눈다.

## 현재 반영

| 영역 | 결과 |
|---|---|
| 로그인·가입 | 승인 HTML의 두 열·제목·글꼴·입력창·안내 순서·버튼 색을 적용. 실제 인증·동의·오류 유지 |
| 비로그인 홈 | 게임 소개 → 가입/로그인 → 시작 방법 3단계. 로그인 폼으로 강제 이동하지 않음 |
| 로그인 뒤 시작 | 배정된 미완료 판이 있으면 테스트 참여를 먼저 펼침. 일반 게임과 테스트는 한 영역씩 선택. 두 기존 시작 양식·이어 하기 유지 |
| 호랑이·글꼴 | 공식 로고는 판 시작 전 계정에만 표시. Gowun Batang·공식 Pretendard subset·OFL 전문 제공 |
| 밤·회의 배경 | PR #323의 정식 manifest 그림을 사용. 앞서 만든 임시 대체 그림·표기·옵션은 제거 |
| 게임 화면 | dev의 기존 VN 기능 유지. B-10-08이 회의·밤·결과 전체를 새로 구현한 것은 아님 |

## PM에게 전달할 내용

호랑이·시안 글꼴·밤 원화의 사용 승인을 다시 요청하는 것이 아니다. 기존 승인 시안과 실제 기능을 함께 유지하기 위해 아래 범위와 검수 기준을 정리해 달라는 요청이다.

| 순서 | 현재 차이·원인 | 권장 정리·확인 요청 |
|---|---|---|
| 0. 로그인 배경의 기준 버전 | 보존한 HTML의 로그인 CSS에 직접 들어 있는 그림은 달이 크게 보이는 장면이다. PR #323의 공식 night는 더 어두운 다른 마을 장면이며, 태스크는 공식 night를 요구한다 | 동일 파일명 시안의 기준 버전·원본 SHA와 로그인에 쓸 그림을 명시해 달라. 현재는 태스크의 공식 night 유지. 보존 HTML의 로그인 그림까지 정확히 맞추려면 계정 배경의 담당·공식 ID 또는 night 원본 선택을 문서에서 확정한 뒤 반영 |
| 1. 로그인 이후 로비 | HTML의 독립 로비는 전면 배경·무당·시작 설정을 함께 쓰지만 B-10-08 문구는 홈을 로그인 화면 배치로 적용하도록 되어 있다. 현재는 계정 두 열과 실제 양식 유지 | 시안 로비 전체의 담당·태스크 범위를 명시. 권장: 승인 로비 외형을 후속 범위에 포함하되 시작 UUID·배정 회차·모습·열린 결말·광고·이어 하기 보존 |
| 2. 창의 종이 질감 | 시안의 종이 결 이미지는 현재 정식 manifest ID·규격이 없다. 계정 창은 색·선·약한 CSS 명암을 적용 | 완전 일치가 필요하면 같은 원본 질감의 정식 등록과 규격·담당 태스크를 E에게 배정. B가 새 자원 유형·계약을 임의로 만들지 않음 |
| 3. 계정 문구·첫 화면 | 가짜 ID·‘화면 확인’·시안 경고는 실제 서비스와 맞지 않음. 사용자 요청으로 게임 소개·시작 안내와 일반/테스트 선택 보완 | 현재 문구·순서를 제품 검수 기준으로 확인. 실제 동의 전문·오류·비밀번호 안내는 기존 원문 유지 |
| 4. 전체 게임 디자인 | 회의·밤·첫 등장·공개 사건 표정·결과는 B-10-08의 계정 범위 밖 | E B-10-07과 관련 결과/에셋 태스크에서 동일 장면·동일 폭으로 시각 검수. 기본 전신 배치만으로 전체 시안 일치를 판정하지 않음 |

정식 밤·회의 그림 등록은 최신 dev에서 해결됐다. 이를 E의 미구현 항목으로 다시 배정하지 않는다. 실제 정식 배경 위에서 VN 연출 전체를 확인하는 잔여와 구분한다.

## 완전 일치 판정 방법

1. 로그인·가입·비로그인 홈·로그인 뒤 로비·회의·밤·결과를 각각 같은 상태와 1280/360px로 캡처한다.
2. 배치·창·색·글꼴·이미지·조작 위치를 비교하고 차이를 기록한다. 실제 인증·동의·오류와 확정 모바일 VN 배치는 의도한 차이로 구분한다.
3. B와 E의 화면을 최신 dev에서 함께 확인한 뒤 PM이 시각 검수를 마친다. 기능 시험과 시각 검수 통과를 따로 기록한다.
