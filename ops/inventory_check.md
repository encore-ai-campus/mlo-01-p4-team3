# VM 점검표 (C-05-01)

3차 프로젝트 VM 20대를 4차에서 다시 쓰기 전에 상태를 확인하는 양식이다. 각 노트북 담당이 자기 노트북 VM 4대를 점검해 아래 표의 자기 행을 채우고, C가 20대 표로 모은다(`docs/tasks/C_infra.md` C-05-01). 논리 서버명만 쓰고 IP·계정·비밀번호는 쓰지 않는다(기획서 6.3). 접속 정보는 저장소 밖 비공개 문서에 있다.

## 점검 방법

1. **호스트(노트북, Windows)**: VMware VM 폴더를 읽어 기동 여부·vCPU·RAM·디스크·스냅샷 수와 호스트 디스크 여유를 한 번에 출력한다. VM이 꺼져 있어도 된다.
   ```
   powershell -ExecutionPolicy Bypass -File ops\inventory_host.ps1
   ```
   VM 폴더가 기본 위치(`문서\Virtual Machines`)가 아니면 `-VmRoot "<폴더>"`를 붙인다. 폴더 이름이 스크립트의 대응표(`pj3-…` → 논리 서버명)에 없으면 "(프로젝트 밖)"으로 나오니 논리 서버명을 직접 고쳐 적는다.
2. **게스트(VM 안, Linux)**: VM을 켜고 SSH로 들어가 OS·Python·vCPU·RAM 사용·디스크 사용·서비스 상태를 JSON 한 줄로 받는다. 스크립트를 VM에 복사할 필요 없이 표준 입력으로 넘긴다.
   ```
   ssh <접속 별칭> 'bash -s <논리 서버명>' < tools/perf/vm_probe.sh
   ```
   출력에는 IP·hostname이 없다. JSON의 값을 아래 표에 옮긴다.
3. 기동이 안 되거나 SSH가 안 되면 "기동 안 되는 VM" 표에 증상·원인·조치 계획을 적는다.
