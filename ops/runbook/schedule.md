# 실행 시간표 (C-05-02 초안)

노트북 VM 20대를 시간대별로 어떻게 쓰는지 정한다. 근거는 `vm_roles.md` "배치 근거와 자원 운영"(노트북 3의 LLM 시간대, 노트북 4의 학습·시뮬레이션 분리, v1.1 기획서 6.3에서 옮김)과 태스크 문서의 날짜다. **시각은 근거 문서에 없어 모두 "제안"**이다. 담당 C가 확인하고, 11/6 C-06-04(LLM 최종 자원) 뒤에 노트북 3 행을 고친다.

## 시간대 종류

| 시간대 | 하는 일 | 지킬 것 |
|---|---|---|
| 개발 | 각자 노트북에서 개발, 로컬 Compose | llm-01은 작게 두거나 정지(가짜 LLM `fixtures/llm`으로 개발). 노트북 3 담당은 개발 도구를 그대로 쓴다 |
| 통합·LLM 측정 | INT, LLM 벤치·MVP 측정 | 노트북 3 담당은 개발 도구를 줄이고 llm-01에 확정 배정량을 준다. 측정 중 다른 무거운 작업 금지 |
| 사용자 테스트 | 사전·정식 사용자 테스트 | **llm-01·ad-01·app-01이 있는 노트북(2·3)에서 학습·대량 시뮬레이션 금지**(C-05-02 조건 3). 노트북 4의 학습도 미룬다 |
| 학습·시뮬레이션 | ML 학습(nifi-01), k3s 대량 시뮬레이션(spark-worker-03 등) | 노트북 4에서 학습과 시뮬레이션을 같은 시간에 돌리지 않는다(`vm_roles.md`) |
