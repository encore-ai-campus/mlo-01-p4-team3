# 실행 시간표 (C-05-02 초안)

노트북 VM 20대를 시간대별로 어떻게 쓰는지 정한다. 근거는 `vm_roles.md` "배치 근거와 자원 운영"(노트북 3의 LLM 시간대, 노트북 4의 학습·시뮬레이션 분리, v1.1 기획서 6.3에서 옮김)과 태스크 문서의 날짜다. **시각은 근거 문서에 없어 모두 "제안"**이다. 담당 C가 확인하고, 11/6 C-06-04(LLM 최종 자원) 뒤에 노트북 3 행을 고친다.

## C-06-04 11/7 추가 인계 (P-31 반영)

기존 노트북 3 LLM 상시 배정·예열 제안은 P-31 이전 기록이다. 현재 게임 테스트는 템플릿·검수된 변형 경로로 진행하며 LLM endpoint 기동을 선행 조건으로 두지 않는다. E-10-13은 Claude Code로 사전 작성·검수하고(11/8 사용자 결정, 로컬 LLM 미사용) E-11-12(11/11)는 계정별 RunPod Pod로 GPU LLM NPC 대화 서비스 시연만 수행한다(11/8 사용자 결정, 게임 미연결). 비용·실험 시간을 확인한 뒤 기동·측정·결과 보존·정지한다. 실제 Pod 생성이나 기존 llm-01 정지·RAM 반환은 미실행/미확인이다. [GPU 실험 런북](runpod.md). Garage 두 노드는 계속 사용한다.
